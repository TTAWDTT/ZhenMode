# 柱平均、压力与实际通量的一致性实验

前轮主网格海面误差为0.005240393934376391，垂向节点加倍后约缩小3.89倍；水平网格加倍的变化很小。已有开发诊断显示，均匀节点余弦模式的容量平均含二阶梯形误差。单独三次压力积分使海面误差变大，因此不能只替换压力平均或只替换海面连续性。

新增可选 `column_mean_scheme=cubic_consistent_v1`，以各均匀区间四节点三次积分累加得到柱积分权重Q。它是物理点值的柱平均，不更改 `dz_node`、节点位置、T/S库存或原评分定义。速度柱平均、密度压力平均力和joint_shear分解使用同一Q；内部压力仍采用前轮三次积分。

实际水平层质量通量保留原容量生成的通量，再按h/H分配柱差Δ=H*Q(u_face)−sum(h*u_face)。这样实际质量面总和等于高阶柱平均，而不将梯形层总和和高阶外模混用。垂向Fz由这些实际面的散度逆积，水平示踪通量也使用同一实际面，保持常量、边界库存和外模两次连续性输运的一致性。这实际改变了各层输运速度，不能称为只修改平均数计算；修正不保证任意CFL或全模型单调性。

设w=h/H、q为归一化Q，修正是P=I+1(q−w)^T。由于q*1=w*1=1，P保持常量，w^T*P=q^T；新mean为零的shear经实际面修正后不会驱动外模。仿射剖面的新旧积分相同。此为均匀全湿线性EOS、物理表底、unsplit symmetric、closed_faces、centered_fourth、joint_shear和三次压力的受限选项，至少六节点。默认容量mean路径保留。
