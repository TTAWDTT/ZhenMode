# 固定参考部分单元与阶梯海底面联系

`make_solver_global(..., column_geometry="fixed_partial_v1", conservative_kv=True,
localize_conv=True)` 是显式选择的 FD 算子候选。它保留固定深度上的温盐和速度点值、
线性自由面，将参考水柱截到实际海底；一个湿节点的浅海水柱使用其真实厚度。
原生产入口和 `legacy`、`nodal_dual_v1` 路线仍按原定义运行。

相邻湿节点之间的参考单元边界取节点深度中点，最后一个湿节点的单元延伸到海底。
因此两柱同编号单元厚度取最小值不能表示完整开口：浅柱的末单元可能同时接触
深柱的同编号和下一个节点单元。候选保存节点差为 0、+1、−1 的三类区间交集，
每类含重叠厚度与中深；经度周期，纬向边界关闭。真实 1° 输入上的开口覆盖检查
仅是几何证据，不能替代动力稳定性或物理过程资格。

每个联系先计算实体积通量，再分别散入两个端点，最后除以接收单元的本地厚度。
速度取两个端点平均，梯度将半个加权压力差散到双方；在当前兼容球面度量和固定
参考容量下，这是一对体积加权的负伴随算子。示踪物分别支持原有中心、供体及
MUSCL 选择。实际快步接受的二维面通量由全部联系和节点共同求和，随后用于
匹配示踪物输运和分项预算；投影预条件对角按同一联系算子计算。

动量的水平物质导数也使用实际联系面通量，等价于
`D(F*mean(u))-u*D(F)`，以端点差计算来精确保留常量。垂向节点导数及非线性
去混叠仍为独立阶段；不由此声称完整动量／动能守恒，或阶梯海底上垂向剪切
的连续重构准确性。自由面 eta 的完整三维联系梯度在非线性残差中逐节点抵消，
随后由外模步处理，不能只减列平均而留下伪剪切。极区的二维外模速度按水柱
参考深度加权，eta 保留面积／湿点平均，两者使用不同的容量。

底层 `make_fd_params` 返回的参数也显式携带几何选择，避免通用算子退回旧路线。
固定部分单元入口要求有限正度量，并核对 `dx=L*cos_lat` 的兼容关系；仅允许
浮点舍入范围内的差异。任意独立指定的水平度量不能套用这些守恒恒等式。

跨节点的压力不能直接相减 `P(z_k)` 与 `P(z_(k+1))`。候选将双方压力重构到同一
联系中深；同编号联系保留原节点深度。底端持值的温盐续接只提供压力插值锚点，
不增加水、热或盐库存。常温常盐水柱的平衡测试不认证一般层结的重构误差：
层结静止、加密收敛、短窗稳定性及实际初态仍是独立检查项。重构后的密度压力
梯度也不自动继承标量联系梯度的负伴随证明。

2026-10-06 的解析控制固定四柱床深 33、73、113、150 m，取各柱相同的线性密度
剖面 `rho_prime=0.01*z_positive_down`，精确水平加速度为零。30、15、7.5、3.75 m
均匀垂向间距的最大残余加速度依次为 3.7767e−8、1.4007e−8、2.0110e−9、
6.8134e−10 m/s²。这是实现后的一组有限加密观测，没有据此拟合合格阈值，
没有证明普遍收敛阶，也没有进行全球六小时积分。原始脚本、输入定义与有界
运行收据应随工程证据归档；完整 case 的层结和分项预算仍需另检。

表面施热、垂向守恒扩散、最深湿节点底摩擦、极区平均及参考库存使用实际单元
厚度。参考厚度不随 eta 移动；eta 位移库存和顶面示踪物通量仍须单列。准备器
按经纬 bounds 算出的精确球面面积，与现有 FD 的 `dx*dy` 中点面积需在正式 case
中统一并验证，当前不能把两种库存直接视为相等。

当前候选拒绝尚未适配的 GM、Redi 和旧动态海冰。它不授予完整 OMIP case 执行
资格，也不证明海冰、混合、真实全球积分、气候误差或计算速度。原生初态点场
仍需处理全部湿区支持；MOM6 有独立的层离散和初始化重映射，不能将 FD 点值
文件改标签当作已验证的 MOM6 层平均初态。
