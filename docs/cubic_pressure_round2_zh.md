# 第二轮压力积分隔离实验

端点闭合 `afb6809` 的十组预声明运行已完成，全部原门槛通过。主算例温度误差为 3.6565949126238174e−6 °C，综合分数 0.18282974563119087，仍高于同网格 MOM6 和 Oceananigans 的冻结分数。首轮诊断另发现梯形压力积分的正弦积分误差约二阶，因此新增可选压力积分，独立检查它和端点闭合的贡献。

`hydrostatic_integral_scheme=cubic_uniform_v1` 按四个邻近节点的三次插值积分每段，物理首末区间使用单边四节点。中间区间权重为 (−1,13,13,−1)/24，首段 (9,19,−5,1)/24，末段 (1,−5,19,9)/24。这些系数由多项式区间积分确定，没有拟合算例结果。累计密度压力的各使用方共享同一积分；盐/热库存容量、水平算子、步长和原表面线性密度延伸保持原定义。

首版接受至少四个均匀、全湿、线性 EOS、`nodal_dual_v1` 节点，顶节点 z=0，末节点为物理平底。默认仍为梯形积分。负权重不保证任意密度数据的单调性；这也不是完整自由表面或全模型四阶证明。独立多项式原函数、正弦收敛、EOS 接线和不支持网格的拒绝检查已运行。一次有效接线检查因测试网格默认极区滤波带重叠而拒绝，记录保留；禁用该夹具的极区滤波后通过，生产算法及数值阈值未改变。

端点 limiter 同时改用增量空间计算原有凸组合，以减少相近温标状态相减引起的浮点抵消。数学规则和限制不变，但属于新的源码身份，旧 `afb6809` 运行不重标记为新代码。

运行前固定四个主网格配置：v1/梯形、v2/梯形、v1/三次、v2/三次。v1/梯形必须逐数组回放上一轮冻结数据。两组三次方案先测时，再按同一资源限额执行剩余预声明行。固定 dt=12.5 s、原物理量、网格、幅值与评分门槛；不扫描其他参数。优先选择预声明的 v2/三次组合，仅当其主分数改善且各原门槛通过才扩大其六组波、null 和热风回归。任一失败完整保留，不能放宽门槛。

内部波属于开发证据。独立空间控制重新在冻结隔离包执行，原尝试因源码窗口变化记为 INTEGRITY REFUSED，未读取或用于调整其数值结果。独立检查记录共享的 PDE、浮点库及节点采样，不能夸大独立性。完整 pytest/MMS CI 必须对应新生产源码，草稿 PR 保持未合并。原参考模型结果不覆盖，比较仅限相同物理投影。
