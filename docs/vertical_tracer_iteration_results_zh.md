# 垂向温度输运迭代结果

受限垂向界面重构解决了原内部波对照中四组 16 层温度误差超标。六组候选内部波、候选零扰动、旧默认零扰动及热风回归全部通过原阈值；旧默认主算例全部数值数组与原冻结结果逐字节一致。十次正式原生积分全部完成，其中旧默认主算例仍保留其预期的温度屏障失败，没有改变默认算法或阈值来消除这个基准差异。

主网格温度 RMS 从 2.46514865e-5 降至 6.18991423e-6 °C，原阈值为 2×10⁻⁵ °C。复合分数从 1.23257433 降至 0.309495712。这些数据支持该受限候选改善当前已知误差，尚不支持全球资格或 SOTA。

## 修改范围与边界

新增显式选项 vertical_tracer_scheme=muscl_nodal_v1，以物理节点距离构造内部 minmod 斜率，给出相邻浓度范围内的迎风界面状态。物理顶/底端点保留 donor 状态；干层后的末湿节点退回零斜率。默认仍为 donor_cell，水平输运、步长、EOS、压力/旋转、实际连续性通量和表面/底部通量保持原样。新开发契约逐字段还原后与旧物理契约哈希相同，除垂向选项外没有改变设置。

极端非均匀节点存在现有容量 CFL 无法控制重构出流库存的反例，因此首版 factory 拒收非均匀垂向节点，只接受均匀 nodal_dual_v1。早期端点一侧斜率还会从零浓度端点向外输出正库存，修订后物理端点保留 donor。早期 prototype 和反例记录全部保留，其较低内部波误差不能代替正性控制。完整耦合 RK2 的任意 CFL、全局 TVD/正性、世界海洋网格与气候预算均未认证。

## 独立检查和软件验证

独立作者的 sin⁴/logistic 闭端点输运控制已用于发现端点问题，因此它属于开发/回归控制，不是修订后未见验证。修订后在均匀容量 CFL=0.1 的单 Euler/Heun 步，三个分辨率保持非负、端点零值和库存；非均匀反例仍产生负值，必须保留 factory 拒收。

另在代码冻结后预声明二维闭壁流函数稳态染料控制，染料是流函数的函数，连续 material tendency 为零。单次检查的归一化体积加权 L1 残差随网格加密为 0.00715286367、0.00188581448、4.76187064e-4，两个加密比大于 3.79；常量与库存控制通过，反号垂向通量被常量缺陷控制拒绝。结果未用于改本轮参数。它是纯空间输运算子检验，共享指定连续方程、原生取样及生产连续性通量，不是完整海洋物理或时间积分认证。
