# 对齐并超越成熟海洋模式：持续验收路线

用户目标（保持完整）：自主迭代，直到能够对齐乃至超越工业级模式；
充分调研再动手，每次大动作前重新调研。

本路线不把“一次跑通”“某个 SST 分数更低”“小网格 JIT 更快”当作完成。
连续工作由当前 active thread goal 驱动，不另建重复定时任务。

## 参照与完成证据

首轮参照是 MOM6、MITgcm、NEMO 的公开数值/诊断文档以及 OMIP 评估实践。
它们不是同一个配置，不能把一个默认运行速度或局部指标作为行业上限。
最终验收需要固定具体版本、配置、输入、硬件和统计范围。

“对齐”要求上述目标配置的必要能力和验证都通过，不能以速度抵消错误。
“超越”要求在公平比较中至少有实质性、更优的误差/预报技巧或成本收益，
且其他必需门槛不退步；不能只报告最好的一个观测区域或删除困难海域。
具体误差和性能门槛须在相应正式实验前冻结并说明应用依据，不能事后定线。

## 迭代规则

1. 调研对应物理、数值方法和成熟实现，保存来源和本项目适用/不适用边界。
2. 写入实验协议与反证条件，再提交协议；避免读到结果之后挪验收线。
3. 在当前代码上复现，先让直接回归失败，再最小范围实现根因修复。
4. 顺序验证算子、完整步、理想动力学、真实地形、真实强迫、生产长期。
5. 保存输入/源码哈希、原始结果和失败，报告因果范围，不把窄测试当最终成功。
6. 定期回到本表审计缺失能力。文献、代码、测试和外部跑例改变时重审结论。

## 推进顺序

- **P0：离散预算基础。** 默认温盐 Laplacian/biharmonic、GM/Redi、
  对流、滤波和极盖逐项计账，最终建立实际阶段/子步的热盐水账本。
- **P1：体积与自由面、垂向表示。** 决定节点到有限体积/部分单元的迁移，
  不能单纯把相同数组塞进 ALE 模式当作等价几何；极区与海峡连通需单独研究。
- **P2：真实边界与物理闭合。** 完整热/淡水通量、状态方程、垂向混合、
  等密度混合与海冰，在预算门槛下逐项加入。
- **P3：观测和成熟模式对照。** 先校正面积加权、物理滤波、时间平均与覆盖，
  再跑同输入动力学控制及 OMIP 风格气候实验。稳定测试与技巧评分分开。
- **P4：百年与预报验收。** 用生产参数完成长跑/敏感性及留出回报；
  加速自旋升的异常参数只生成初值，不能作为最终气候态。
- **P5：GPU/分布式、学习。** 可以并行研究，但只有在同等误差和物理约束
  下的可重复成本收益，才计入“超越”；不先用网络掩盖守恒缺陷。
