## 可判定定义

深度 `d_k=-z_k`，参考厚度 `h0=dz_node*wet`，面积 `A=dx*dy`。
动量质量为 `M0=rho0*A*h0`。线性 EOS 密度异常是 kg/m³。
材料密度库存 `C_rho=(h0+eta*surface_mask)*rho'` 是 kg/m²。
候选 `E_rho=-g sum(A*d_k*C_rho)` 是 J；只是一阶节点高度矩，
尚不是移动控制体的物理高度积分或完整机械能。

在 T/S extensive 库存上求导必须包含容量参考项：

```
C_rho_dot = rho0 * [-alpha*(C_T_dot-T_ref*h_dot)
                    +beta*(C_S_dot-S_ref*h_dot)]
```

漏掉这些项会使零密度异常、均匀参考 T/S 在容量变化时获得伪密度源。
测试直接调用原 scalar advection，验证修正后为零、未修正项非零。

本次 fixture 为 8×3×4 全湿平底，节点深度 `[0,5,20,50]m`，
参考控制厚度 `[2.5,10,22.5,15]m`，含非均匀纬度 cos 度量。
eta=0 上求瞬时率；moving_top_exchange 表示非零 eta_dot，不是一段移动轨迹。
实际调用原压力/梯形积分、共同湿面梯度、节点面输运、柱连续性逆算和 donor
scalar 算子。六个所用函数 AST 与 PR7 执行历史源 `212df951...` 相同。
中心垂向通量是独立代数 oracle；生产垂向 donor 即使关 monotone 仍然启用。

## 配对及边界

定义向下正内部接口体积率 `F_k`，共同层水平散度 `D_k`。
原垂向逆算满足 `D_k=F_k-F_(k+1)`，底 `F_n=0`。
材料相对顶界 tracer 通量为零：从原 scalar RHS 移除已返回的顶 exchange，
将它转为 `h_dot_top=-F_0`。这不是开放边界入流。
顶节点 d0=0 且密度异常压力 P0=0，因此本候选顶界 PE 与压力边界功均零。
经度周期缝抵消、南北封闭、底输运为零。未实现开放边界功。

平底共同层离散分部积分与梯形积分给出：

```
W_density = sum A*g*Delta(d)*F*rho_mid
E_rho_dot_centered = -sum A*g*Delta(d)*F*rho_mid
W_density + E_rho_dot_donor
  = -sum A*g*Delta(d)*F*(rho_donor-rho_mid)
```

水平 density stock 通量在每个等高层全域求和抵消。上式右端由实际 donor
和中点密度直接计算，绝不从闭合残差拟合。稳定剖面右端为
`g/2 sum A*Delta(d)*abs(F)*Delta(rho)`，非负；倒置剖面可反号。
这是该候选与 donor 的已知配对差，不是总机械能注入证明，也不证明实际
六小时场的差额大小。完整动量输运、黏性和源转换尚未闭合。

## 移动几何仍缺什么

候选顶节点 z=0，故顶密度容量变化对其高度矩贡献为零。
若把顶控制视为均匀密度、实际跨 z=-h0 到 z=eta 的控制体，
其异常 PE 是 `g*A*rho'*(eta²-h0²)/2`，率含 `g*A*rho'*eta*eta_dot`。
例如 A=100m²、rho'=2kg/m³、eta=.4m、eta_dot=.01m/s，几何率为
7.848 W，而节点矩为零。这是明确的定义缺口，不能用 Kmat-Kref 或热库存补。
固定节点值并不禁止定义线性重构的物理 PE，但必须先规定高度重构、控制体
边界、湿底、垂向输运以及压力/速度质量的共同配对；不能仅换 PE 标签。

建议：当前先保留 E_rho 为诊断，单列 donor 通量配对差；不要宣称闭合总能量。
若继续，只验证上述定义在实际阶段的配对及差额，再建立部分湿底/移动顶
几何泛函；不以改中心通量、放宽门槛或拟合转换项来换通过。
本 oracle 明确拒绝部分湿底，不对海盆阶梯、限幅分支或完整模式作外推。
