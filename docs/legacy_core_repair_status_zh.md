## 3. M1：候选合同与原核心局部改动

`make_solver_global(..., column_geometry='nodal_dual_v1',
conservative_kv=True, localize_conv=True)` 在同一个 FD 核心内选择候选。
默认仍为 `legacy`；候选只在测试/API及 smoke 脚本显式选用，生产 CLI 未切换。

状态仍是 `z` 节点点值，**未改名成层平均，也未替换状态结构**。
参考自由面在 0；内界面取相邻节点深度中点；最后界面取最深节点深度。
湿掩膜须为二值连续前缀；浅底截到最后湿节点控制体的下界面，
深于最深节点的水量不表示。第一节点在 0 以下时，第一控制体仍从 0 开始。

例如 `z=[0,-5,-20,-50]`，控制厚度为 `[2.5,10,22.5,15]`，合计 50 m，
而旧参考 tracer 权重为 `[5,10,22.5,30]`，合计 67.5 m。
原始底深 10 m、仅前两节点湿时，候选参考底为 12.5 m；这是声明的台阶近似，
**不是严格重现 ETOPO 或增加真实海水**。

局部改动包括：

1. `H_ref=sum(h*wet)` 与节点平均、密度 PGF 的垂向积分共用权重，干列安全处理。
2. 开放面来自相邻水柱**逐节点共同湿区**；正压散度为实际面厚度输运的散度，
   不用 `H_cell*div(u)`。压力配对为面积×参考厚度范数下的负伴随。
3. 正压子步保留初始垂向剪切面输运与均匀平均面输运的差，
   均匀正压回传后仍能重建实际逐层面输运；保留台阶处 eta 压力的剪切残差。
   **这个静态几何差额不是 M2 要求的时间平均输运。**
4. 表面热、混合层、风、海冰热容量与盐源归一化同步改用节点控制厚度；
   snapshot 诊断显式选择同一几何，不能静默退回旧端点权重。
5. 垂向动量扩散改用共同控制体的保守界面通量；候选拒绝旧非保守垂向
   tracer/非局部对流组合。对流及垂向平流子步按控制体重新定尺；
   对未分步的垂向扩散检查新宽度下的显式稳定性余量，超出则拒绝构造。
6. 底阻力作用于每列最后湿节点；线性阻力在慢步处理一次，候选正压子步
   不再追加全水柱阻尼。原默认路径保持不变。

以上是 M1 候选的一组关联修复，不声称每项对整体解的收益已被单独归因。
float64 恒等式与独立源项容差在测试/`M1_contract.json` 中登记；未因结果变差放宽。

## 7. M2：本轮预先声明的输运合同

- 只在原 FD 核心内增加 opt-in `match_barotropic_transport=True`，
  必须同时选 `nodal_dual_v1` 与 mode split。默认路径和 M1 单独开关不切换。
- 保留原动量预测器及其温盐压力反馈；其临时温盐只用于预测，不作为接受态，
  不计入实际外源账本。快模态仍取该预测器第二个 L 半步后的密度强迫。
- 每个子步使用真正推动 eta 的 **OLD** 速度，叠加同一预测器的冻结垂向剪切，
  累计共同湿面上的逐层体积输运。不是末态速度、单纯列平均速度或事后 eta 拟合。
- 在原第一个 L 半步结束的温盐上重算两个实际 RK 阶段；两阶段及其每个平流子步
  都使用匹配该实际时间平均量的逐层湿面输运。第二个 tracer L 半步随后重算。
  动量预测器不随重算温盐迭代，因此这是滞后预测/校正，不声称整个模式二阶。
- eta 滤波/恢复/sponge 的非输运改变量、最后极盖/墙处理引起的面输运变化，
  均单独记录。不得倒推一个假面流量或添加全局热盐补偿消掉它们。
- 仍是固定节点厚度、线性自由面及原来的 `Fz_top*C_surface` 闭合；不清顶通量，
  不把 `eta*C` 记成外源。这一步消除快慢**时层输运不匹配**，不承诺消除静态
  线性自由面近似的所有库存余项。若热盐仍失败，保存负证据，不改门槛。

本轮运行前定义平流参考库存改变量：每个 RK 阶段/子步按实际时长加权，
`delta I_ref_adv = sum_stage(dt_weight * sum_cell(A * Fz_top * C_surface))`。
这是闭域水平/底面通量相消后原 tracer 方程的顶面项，不是外部大气/淡水源。
记录它与实际平流参考库存变化的差，以及独立的全源预算残差；不得用前者扣掉后者。
`eta*C_surface` 的整步变化也继续另列；静态厚度方程没有承诺两者完整相消。
若近似项过大，依据方案第 3 节报告局部厚度合同升级需求，而非事后更名为可接受误差。

当前风/密度强迫与实际底节点拖曳仍沿 M1 分配；已知的正压/三维 Coriolis
重复分配及动量时间阶数留在 M3。本开关不修它们、不扩大可靠性声明。
`project_adv_vel` 可以仍作用于临时动量预测器的 tracer；实际接受 tracer 不再投影到
零散度，而是匹配真实 eta 输运。实际预算中的零 projection 记录不能用来证明临时投影收敛。

依据：MOM6 要求逐层输运匹配正压时间平均面输运，MITgcm 则明确区分线性自由面
与一致的可变厚度 tracer 库存。采用前者的一致性要求，不照搬其不同网格或垂向状态。
参见 [MOM6 快慢耦合](https://mom6.readthedocs.io/en/main/api/generated/pages/Barotropic_Baroclinic_Coupling.html)
与 [MITgcm 自由面](https://mitgcm.readthedocs.io/en/latest/algorithm/nonlinear-freesurf.html)。

先验证独立 NumPy 面积分、局部连续、恒定 tracer、源项单次计入、滤波变化、
32/64 位及 scan/循环一致性；再按 M1 原参数重跑真实 ETOPO 一天 baseline/ice。
这轮不改黏性、强迫、极盖参数或稳定性停止线；完整 M2/M3/M4 状态待结果更新。

## 24. 移动界面通量首个控制：局地几何守恒

先在冻结失败位置的11个湿节点参考体积上做独立控制，而非立即改完整步。
该柱参考H750m，控制η从`−2.49`变为`−2.51m`、dt600s；层水平散度为登记

真实水平面输运，结果不能转贴给真实1°轨迹。

若厚度变化为`dh_k/dt=a_k*dη/dt`，且`Σa_k=1`，给定层水平散度`D_k`，
则向下的相对垂向面输运必须满足：

`dη/dt=−ΣD_k`，`G_0=0`，`G_(k+1)=G_k−D_k−a_k*dη/dt`。

由此逐层`dh_k/dt=−D_k−(G_(k+1)−G_k)`，闭底`G_K=0`由总和恒等式推出。
表面节点双体积的`a=(0.5,0.5,0,…)`、整柱伸缩的`a_k=h_ref,k/H`都必须
使用对应的相对通量；不能沿用顶层独占位移的`a=(1,0,…)`通量。

独立NumPy逐层恒等式和JAX两阶段内容更新均完成。前两节点分配和整柱
分配的最小控制厚度分别`1.245/2.491633m`，闭底相对输运约`2e−20m/s`；

`0.00456/0.00763`，联合出流强度`0.01545/0.00772`，均在登记门槛内。

浓度变化分别`0.278866/0.278880`，局地常量条件失败；但按其实际外边界
