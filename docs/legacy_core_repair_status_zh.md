## 3. M1：候选合同与原核心局部改动

`make_solver_global(..., column_geometry='nodal_dual_v1',
conservative_kv=True, localize_conv=True)` 在同一个 FD 核心内选择候选。
默认仍为 `legacy`；候选只在测试/API及 smoke 脚本显式选用，生产 CLI 未切换。

状态仍是 `z` 节点点值，**未改名成层平均，也未替换状态结构**。
参考自由面在 0；内界面取相邻节点深度中点；最后界面取最深节点深度。
湿掩膜须为二值连续前缀；浅底截到最后湿节点控制体的下界面，
深于最深节点的水量不表示。第一节点在 0 以下时，第一控制体仍从 0 开始。

例如 `z=[0,-5,-20,-50]`，控制厚度为 `[2.5,10,22.5,15]`，合计 50 m，
而旧参考 tracer 权重为 `[5,10,22.5,30]`，合计 67.5 m。
原始底深 10 m、仅前两节点湿时，候选参考底为 12.5 m；这是声明的台阶近似，
**不是严格重现 ETOPO 或增加真实海水**。

局部改动包括：

1. `H_ref=sum(h*wet)` 与节点平均、密度 PGF 的垂向积分共用权重，干列安全处理。
2. 开放面来自相邻水柱**逐节点共同湿区**；正压散度为实际面厚度输运的散度，
   不用 `H_cell*div(u)`。压力配对为面积×参考厚度范数下的负伴随。
3. 正压子步保留初始垂向剪切面输运与均匀平均面输运的差，
   均匀正压回传后仍能重建实际逐层面输运；保留台阶处 eta 压力的剪切残差。
   **这个静态几何差额不是 M2 要求的时间平均输运。**
4. 表面热、混合层、风、海冰热容量与盐源归一化同步改用节点控制厚度；
   snapshot 诊断显式选择同一几何，不能静默退回旧端点权重。
5. 垂向动量扩散改用共同控制体的保守界面通量；候选拒绝旧非保守垂向
   tracer/非局部对流组合。对流及垂向平流子步按控制体重新定尺；
   对未分步的垂向扩散检查新宽度下的显式稳定性余量，超出则拒绝构造。
6. 底阻力作用于每列最后湿节点；线性阻力在慢步处理一次，候选正压子步
   不再追加全水柱阻尼。原默认路径保持不变。

以上是 M1 候选的一组关联修复，不声称每项对整体解的收益已被单独归因。
float64 恒等式与独立源项容差在测试/`M1_contract.json` 中登记；未因结果变差放宽。

四组均完成一天且有限，但 **C 的热预算残差绝对值比 R 大**，不能叫整体改善。
等效热误差以同域湿表面积 `3.12564666690775e14 m²` 和实际 86400 s 计算；
不以巨大初始热含量作分母。上述是参考域预算，不是已证实的实际变体积热泄漏。
顶面内部输运未改叫外部热源；其实际阶段分解保留在原账本中。

ice 的固定参考盐预算也没有闭合：R 为 `+2.646759e10 kg`，C 为
`+3.169035e11 kg`；不能用孤立海冰源项检查通过盖掉此整步残差。
所有投影最大相对残差约 `1.0e-12`，但投影收敛不证明热盐连续性已匹配。

另一个必须保留的限制：当前平滑/筛选地形体积为 `1.065521803e18 m³`，
R tracer 代理水量 `1.079905364e18 m³`（+1.35%），C 静态参考水量
`9.617820375e17 m³`（−9.74%）。R 小的总差可以有局部误差抵消，
C 明确的截深/台阶合同也**不自动满足实际地形体积或气候精度要求**。
该垂向范围是否足够，须另定用途门槛；不为覆盖深海而静默改变状态/重启合同。

因此当前标签为**修复候选，整体尚未通过**。先完成 M2/M3 的同核心一致性修复，
再上 7/30 天资格矩阵；不因一天未爆炸切换默认或提前开展百年验收。
