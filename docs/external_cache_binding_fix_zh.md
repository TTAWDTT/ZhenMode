# 外部缓存接线修复

真实全球回归准备时，`2069035` 的第一次运行在进入时间循环前失败。
case 预检正确选中了本地风缓存，但 loader 的 `cache_dir=CACHE_DIR` 默认参数
在导入时就固定了安装环境的旧目录；worker 或显式数据接线修改 `CACHE_DIR`
不会改变该默认参数。空气温度两个读取函数也有同样问题。

这使显式缓存配置与实际读取脱节，并可能尝试远端读取。失败原日志保留，
不计为数值不稳定或历史生产方法失败。

三个 reader 改用 `cache_dir=None`，调用时解析当前 `CACHE_DIR`。
不配置外部目录的默认路径与显式传入 `cache_dir` 的行为保持；风应力公式、
插值、温度转换、初态、动力和时间积分没有改变。

负例测试通过真正的 `bind_external_inputs` 和三个真实 reader，设置与选中目录
不同的旧目录，禁止远端 Dataset，核对缓存中的解析常值场。
原实现不能通过这些测试；已有显式缓存读取测试继续覆盖原接口。

历史源码不编辑。全球数值对照给历史 reader 显式传入相同 `cache_dir`，
这个纯输入适配写入 observer receipt；两侧实际数据内容保持相同，
不能把此适配说成原历史环境的无修改复跑。
