# 真实大气来源的受控风应力短窗

本实验在既有平底、规则边界、均匀温盐水域中施加来源固定的实际风应力。
它增加真实强迫来源，检验受迫响应和独立预算；不代表真实区域的海岸、海深、
水团或预报，也没有观测／解析轨迹参照用于模式准确性排名。

使用 JRA55-do 1.4.0 / v20190429 原始 1958 年资料，取
1958-01-01 00:00、03:00、06:00 UTC 的五个天气字段。请求点为 45°N、180°E，
使用最近原始格点，实际为 45.2105381877018°N、180°E。复用已有原始资料读取器，
校验尺寸、发布方 SHA-256、产品、坐标、单位、10m 高度、日历、资料性质及许可。
本次只重新哈希实际使用的五个天气原始文件，不声明其他六个未用角色的当前字节已复核。

用现有 LY2009/Gill bulk 实现，假设水面 15°C、海流为零，分别计算三个时刻的应力。
按 [1/4,1/2,1/4] 梯形权重取平均，即假设应力在原始时刻间线性变化。
应力随后在模拟中保持时间／空间常量；不在积分中重算海流反馈的 bulk 系数。
只施加应力，不施加同时计算的热、蒸发和其他水通量。

本机准备的平均应力为 τx=−0.051594765985923434、τy=0.1626073148808886 N/m²。
完整输入、逐时样本、来源和派生代码字节在本机独立 `real-wind-stress.json` 中保存，
原始天气资料不加入 Git。制造控制保持制造标签，不能作为真实资料执行。

域沿用旋转调整的平底通道与余弦海面初态，8×64×4、H=100 m、T=15°C、S=35 psu。
f 使用实际采样纬度的地球旋转值。dt=50 s，积分六小时、每 900 s 保存瞬时状态。
MOM6 使用原生 `WIND_CONFIG=const`；Oceananigans 使用作者标准顶面动量通量，
其运动学通量符号为 −τ/ρ0；ZhenMode 使用既有表面应力入口。
两种 ZhenMode 外模方案及两个上游模式保持相同物理输入，零混合、零底拖曳、
零热水盐源和零冰。实际配置／来源与未用机制逐项记录。

```sh
zhenmode benchmark prepare-wind-sample --acquisition ORIGINAL/acquisition-1958.json \
  --output NEW_STRESS.json
zhenmode benchmark forced-channel --stress-file NEW_STRESS.json --output NEW_RUN \
  --mom-executable PINNED_MOM6 --mom-source PINNED_SOURCE \
  --oceananigans-cache VERIFIED_CACHE --julia ISOLATED_JULIA \
  --source-revision ZHENMODE_COMMIT
```

派生器及测试使用单 CPU、180 秒、4 GiB 外层限制；真实模式仍逐个执行，
每个工作进程一核 CPU、4 GiB 主机 RSS、600 秒，ZhenMode 与 Oceananigans 要求 CUDA。
准备器报告每个已核验的天气字段／三条记录；失败和中断保留已有日志，不覆盖结果。

诊断记录海面和深度平均速度 RMS（m、m/s），它们是响应量而非误差。
同时记录各时刻动能、自由面势能、顶层速度对应的风功率及梯形累计风功。
风功残差按 max(初始能量、最大累计风功、1 J) 归一化，包含数值过程、表面表示
和 900 秒快照积分误差，不将全部残差解释为真实耗散。
体积、温盐库存相对初值最大变化的工程筛选为 1e−8；不设事后调优的能量门槛。

先运行预置控制：独立 Fortran 系数点对应的天气读写、应力反号三样本零均值、
原始字节改动拒绝；以及机械预算收集器的顶层线性加速、零风功、额外动能破坏。
机械制造轨迹只检验预算组装，不宣称完整流体方程解。
模型源码、所用初态、应力及实际 native 输出分别留存；MOM6 缓存构建收据的历史缺口保留。
