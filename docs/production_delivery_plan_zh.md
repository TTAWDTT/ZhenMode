### 1.1 首批对象与变量

- 首批验收目标网格为现有1°、经度周期、纬度截断约±60°配置；通常360×120×14，
  实际坐标/边界/掩膜以运行清单为准，不拿`GlobalGridConfig`的±85°默认值代替CLI。
- 垂向为14个节点样本，不称14个等厚有限体积层：0、5、15、30、50、75、100、
  150、200、300、500、1000、2000、4000m。真实海底与可表示水柱差异必须报告。
- 状态为三维u/v/T/S、二维eta/ice；w为诊断量，不能冒称独立预报状态。
- 主验收包括mode-split；单体路径保留回归。float64为首轮数值参照；
  float32、scan及CUDA单列资格，不能继承float64/CPU通过结论。
- 2°只作资源预检/独立配置，不替代1°验收；0.45°旧评分协议也不替代本次1°资格。
- 简化海冰、GM/Redi、恢复、极盖等按开关分别列覆盖。没有验证的过程不纳入交付声明。

## 7. S3：原FD数值修复的最小依赖闭环

**目标：处理已定位的一致性问题，不再同时试多种替代核心。**
先复用/审查已有M1/M2/M3代码和测试，仅补缺项；生产默认与候选默认分开。
当前`process_time_scheme != legacy`依赖matched transport，后者又依赖nodal geometry。
因此不能只打开一个时间开关，或盲目摘取对流/Coriolis的几行代码。

### S3.0 必须先作的物理合同决策

1. 写出节点权重、参考水柱、湿面厚度、正压平均与压力/散度配对。
   50m列被legacy权重表示为67.5m的已有反证必须由独立几何控制检出。
2. 第一候选仍优先保留FD点样本与线性自由面家族，但选定一致参考几何；
   nodal_dual_v1只在其台阶/深截断政策明确、源/压力/混合依赖都过线后晋级。
3. 该合同不自动解决真实移动库存。若应用预算要求无法在声明的线性近似下满足，
   以独立推导和实测量级证明后，提交局部厚度升级的范围决策；**停止晋级，不能
   擅自扩成material/r-star重写，也不能把未解释余项改名为近似误差。**

### S3.1 几何与输运（先于过程时间修复）

1. 核对已有`make_fd_params`、nodal权重、共同湿面输运、底节点/深截断处理；
   对浅列、台阶、干哨兵、墙、零流/剪切用独立NumPy计算。
2. 核对实际推动eta的正压子步面输运平均；示踪接受阶段必须使用相容的时层/面输运，
   不能拿最后速度代替平均，不能把顶面内部输运登记成外部热源。
3. 核对快慢回传、滤波/极盖之后的连续性、恒定tracer和列积分；源不得重复分配。
4. 已有投影控制继续检查**实际**输运残差，投影收敛不能代替几何与时层一致性。

### S3.2 过程修复（一次一个）

1. **对流：** 保持物理κ，只按子步缩短时间；固定κ改变子步数，与独立矩阵/高精度
   参照比较。子步离散误差可以改变，但有效混合系数不能随n变成κ/n。
2. **Coriolis：** 区分慢剪切与快均值，确保均值旋转只分配一次；解析旋转检验
   幅值/相位及无外力动能，随后核验完整快慢耦合，不只测局地旋转helper。
3. **底拖曳与重力波：** 保留已验证的稳定子算子；分别核验解析拖曳、墙约束、
   波相位/耗散和压力功。对称子过程二阶不能自动推出整个L/N/L二阶。
4. **非线性阶段/子步：** 检验实际接受的动量与tracer阶段，避免两次旧速度求值、
   平均有限步映射冒充瞬时RHS；复用现有oracle并补完整步有源/耦合控制。
5. **联合稳定限制：** 从有效几何检查水平/垂向/双调和、平流/对流、正压波约束；
   各项分别安全不代表联合更新安全。报告最坏位置/项、实际子步与拒绝原因。
6. 表面热/冰、GM/Redi、恢复与滤波在新几何下复核已有控制，未覆盖开关标unsupported。

**G3：** 该候选全部依赖控制、独立源预算和实际完整步通过预注册门槛；
出现改善一项却恶化稳定性/物理误差时拒绝该补丁，不通过加黏性“补救”。
新候选可以显式选择，但默认切换必须另有完整S4/S5证据与迁移说明。

## 9. S5：真实强迫阶梯积分与资源预算

**目标：以目标1°配置实测，不以合成控制或2°成功替代。**

### 运行顺序

1. 预检实际ETOPO/WOA/风/空气温度、网格、初值、有效参数和严格来源；输入缺失先停。
2. 1°、float64、mode-split，先跑100步/短窗，验证逐步监测与完整账本输出。
3. 同一配置依次1天→7天→30天；各段可从同合同checkpoint延续，记录累计时长，
   不把三段长度相加冒充独立长度。通过后跑跨季节365天实历长度压力试验。
4. 至少在共同的1/7天窗口做dt减半、连续/重启；CPU/CUDA和float32只比较各自已
   支持的配置。未完成的后端/精度标未验收，不阻塞其他配置的有限范围报告。
5. 固定月份30天与季节强迫分别列证据；旧30天结果只作参考，不重复标为C通过。
6. 30天/年级报告检查分海盆、上/深海温盐、预算残差、eta/速度、过程尺度与首异常；
   SST稳定或全域平均相抵消不能掩盖局地/深层错误。

dt=60及mode-split候选600/50s只是待预检的协议备选；最终只冻结一个安全生产组合，
不得在长期运行途中改dt/κ/黏性/恢复。若600/50不能过完整步，保留失败，不以短窗
成本强行采用；更小dt的新配置也须单独记录，不能抹去旧配置失败。

### 算力、存储与工期

- 首次真实短窗测编译、同步完整步、监测/账本、checkpoint和输出的分别耗时；
  不把异步dispatch时间或早期GPU数字当作实际吞吐。
- `N_step = D*86400/dt`；`预计计算时间 = N_step*实测每步时间 + JIT + I/O`，
 另报重复样本波动、失败重跑预算和磁盘余量，不先承诺几小时完成百年。
- 月/年均量使用时间权重和固定大小在线累计；保留关键原始窗口/checkpoint与失败态，
  不保存百年每步全三维场。每步单状态1°float64约20MB（不含工作数组），须按实际
  shapes/dtype重算存储，不能由该数估算峰值显存。
- 运行目录唯一，已存在输入/结果不覆盖；代码/输入变化则新批次重新资格。

**G5：** 实际365天窗口及敏感性达到冻结判据；未解释累计预算/失稳即停。
这仍不是百年/气候技能，不能以365天时间外推代替S6。

## 10. S6：百年可靠性与独立气候态

按[百年与气候验收要求](century_climate_acceptance_zh.md)，完成两个独立工作包。

### S6-L 长期可靠性

1. 明确自旋升、控制积分与历史强迫回算的区别，冻结“100模式年”的日历定义。
2. 有效生产参数完成100模式年；恢复/稳定化按协议保持并计账，不中途调参或重置漂移。
3. 年度验收库存/源残差、分海盆和0–700/700–2000/2000m以下趋势、输运/海面量。
4. 至少保留一次共同窗的dt减半、合理初值扰动、精度对照与多次重启。
   同环境短重启遵守字节要求；百年混沌统计不要求跨硬件逐格逐位相同。
5. 首拒绝保存证据，已接受年数照实报告，不能从另一个配置拼满100年。

### S6-A 气候精度

1. 在调参前确定同年代/域的独立参考、20–30年评价窗、观测QC/覆盖、时间权重。
   自旋升充分性由上/深海及环流判断，不能把第100年自动当平衡态。
2. SST/SSS面积加权偏差/RMSE、季节幅值/相位、三维温盐湿体积误差、SSH/混合层/
   环流输运分开评价；未覆盖极区/深底不能声称全球极区或深海资格。
3. 恢复/同化目标不是独立验证；WOA初值比较仍属受约束诊断。留出年代/区域/观测
   不能同时用于训练调参；原始尺度与预注册共同尺度都保留。
4. 冻结成熟模式具体版本/同强迫配置，用相同评分域/参照/覆盖与权重；
   因缺测删除难区、混用旧/新评分定义或不同强迫的排名均无效。
5. 绝对业务误差阈值在正式评价前由用途/观测不确定性确定；目前没有证据支持
   预填“SST<某值”等达标数字。至少要求已选关键指标不显著劣于公平基线，
   “超过”须在预选主指标上有超出统计不确定性的改善，其余预算/动力指标不退化。

**G6-L/A：** 分别出具PASS/FAIL/缺数据报告。只有两者都合格，才可同时声明
“该配置百年可靠且气候态精度达到所列标准”；不得笼统声明完整工业级。

## 11. S7：预报资格，不把强迫回算称为业务预报

**目标：证明模型在指定预报时效对独立观测有技巧，而不是平均场更接近初值。**

1. 先固定预测对象/时效：首轮建议1、3、5、7天；这是待注册目标，不是已有能力。
2. 起报时只使用当时可获得的初始/边界/大气预测资料；未来再分析驱动的实验
   标“完美强迫回算”，与可实现业务预报分开。
3. 准备跨四季起报集，初步最低每季3个起报日；实际样本量根据相关性/置信区间
   再冻结，12次不是充分统计保证，也不是所有季节/极端情景的证明。
4. 观测空间按同时间、位置、深度配对SST/SSH/Argo温盐及可用流速；记录覆盖、QC、
   代表性误差，未被同化的资料优先独立检验。不同预报时效分别评分。
5. 比较持续性、气候态及一个具体成熟系统的同条件结果，报告偏差/RMSE/技巧分数
   和置信区间。某时效没有胜过持续性，保留该FAIL，不能仅挑最好的起报。
6. 标明未包含潮汐/极区/真实海冰等功能造成的适用边界；用户用途若必需这些过程，
   先作范围/资源决策，不能从现有简化模式直接承诺。

**G7：** 预注册时效/主变量的独立技巧和工程时限合格，其他变量明确列未覆盖。

## 12. S8：可微、可学习与公平性能

### S8-D 梯度与约束学习

1. 复用局地JVP/VJP与有限差分，增加完整短窗目标（温盐/SSH损失）的方向导数/
   Taylor检验和ε扫描；包含强迫、参数及初值路径。
2. 对流门控、限幅、相变等切换点单列；远离切换的局地通过不推广为全域光滑。
3. 注册短窗长度与梯度容差；检测截断/stop_gradient是否与实际训练目标一致，
   checkpoint反传与未checkpoint短窗对照。当前不承诺百年可用梯度。
4. 用一个已有可学习物理参数作最小训练，不接新网络模块；训练/验证/测试资料分离，
   物理约束与稳定性纳入门禁，留出改善不能以预算恶化换取。

### S8-P 性能与并行

1. 固定数值/物理合同、输入、dtype、分辨率和容许误差后，先测CPU及单GPU完整步。
2. 分开JIT冷启动、热步、I/O、账本、反向梯度、峰值设备内存；同步计时，多次重复。
   报SYPD时注明一个模拟年的日历长度，同时报秒/步和网格规模。
3. 按剖析热点优先复用scan/已有JIT和减少不必要传输；每个优化重新过正确性门槛。
   不因快速float32结果与float64参照不同就忽略数值资格。
4. 与成熟模式固定硬件/精度/物理复杂度；无法匹配时标“非等价成本参照”，不排名。
5. 多GPU/分布式另立工作包，先定义域分解、halo、归约、重启和跨设备数值合同；
   当前没有实装/验收，不纳入首批交付，也不以数组并行宣称MPI/多GPU能力。

**G8：** 仅对完成的梯度窗、学习任务、硬件/配置发布指标。对某项工业基线更快
且误差/物理约束不退化才能称该项超过；不以kernel速度替代端到端结果。

- [MOM6快慢模态耦合](https://mom6.readthedocs.io/en/main/api/generated/pages/Barotropic_Baroclinic_Coupling.html)：平均正压输运与慢过程一致，而非末态替代。
- [MITgcm自由面与库存](https://mitgcm.readthedocs.io/en/latest/algorithm/nonlinear-freesurf.html)：线性近似可以有声明范围；非线性厚度/连续性/tracer必须一致。
- [OMIP实验与诊断](https://gmd.copernicus.org/articles/9/3231/2016/)与[OMIP-2评价](https://gmd.copernicus.org/articles/13/3643/2020/)：长期模拟、强迫和气候评价协议。
- [OceanPredict验证](https://sp.copernicus.org/articles/5-opsr/16/2025/)与[Class 4比较](https://sp.copernicus.org/articles/5-opsr/17/2025/)：观测空间、分时效、覆盖和独立性。
- [MITgcm梯度核验](https://mitgcm.readthedocs.io/en/latest/autodiff/autodiff.html#the-gradient-check-package)：AD结果需要独立导数验证。

以上是方法/验收参照，不是本项目获得认证。旧计划与状态作为历史证据保留；
当前执行排序以本文为准，长期能力要求以本文与百年/气候验收文件共同为准。
