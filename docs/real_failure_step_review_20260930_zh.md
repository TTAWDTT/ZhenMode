# B：真实 1° 单失败步的源码审查与下一步决策

## 决策

两档在同一位置、同一模型时刻跨过固定顶节点的正厚度边界，直接阻塞是几何，
不是这一步的容量。继续增加容量不能修复该状态。当前证据尚不能判定 eta 下降
物理正确，故不提交夹厚度、减小原 dt 或改体积权重的数值补丁。
下一实验应先归因 eta，再决定是否存在局部动力修复；无需启动长期积分或新坐标候选。

## continuity / pressure / transport / source 审计

1. **体积与库存**：material_thickness 用 `dz_node + eta*surface_mask`，
   顶参考厚2.5 m吸收全部 eta，其他湿节点厚度不随 eta 变。
   `_contents` 用这个移动顶体积乘 T/S；整柱有水不能保证每个控制体为正。
   `_concentrations` 对非正厚分母暂用1，原valid门禁仍拒绝；这不是正性修复。
2. **continuity**：`_barotropic_subcycle_transport` 对称快模子步记录真实面输运均值，
   其层面输运用参考 dz_node。`_symmetric_free_surface_step` 两次半漂移推进 eta，
   中点压力 kick 含旋转、风及密度压力贡献；过滤/松弛等非输运改变量另记。
   material完整步检查 `eta_attempt-eta_start + dt*div(column_faces)` 与
   `filter_change`，但当前转述没有其数值，不能声称这些检查已通过。
3. **压力与动量**：静水密度压力积分用固定 dz_3d，加 `rho0*g*eta`；
   柱压力梯度/速度范数及风响应用参考深度/参考表层厚度。
   快模没有 material顶节点正性约束。这是参考几何动力与移动顶库存之间的
   已知适用域边界；仅凭引用公式不能断言压力符号错误或下降是假信号。
4. **输运**：`_match_layer_face_transports` 按参考厚度分配柱输运修正，
   各层和匹配柱面输运；`_vertical_transport_iface` 由同一层散度自底累计。
   material RHS 将参考浓度倾向乘 dz_node 转为内容倾向，并扣除参考表面交换，
   使自由面体积变化与库存配对。端点非正时 `_subcycle_plan` 激活0子步。
   required37/18用安全分母算出，不是负体积下可执行的CFL资格。
5. **source**：表面热/盐等在参考几何倾向里归一化，material RHS再乘 dz_node，
   内容源积分和库存门禁配对。因此不能只把source分母换成最小厚度。
   更改体积、输运权重或动量受力，都需同时审计单位、面积加权库存、
   均匀示踪剂与source零/非零测试；孤立改分母会改变合同。

## 最小反证实验、修复选项与退出标准

**优先实验：原失败步的只读 eta 归因，不再完整积分。**
保留历史源码、原输入、固定forcing与256合同，在快模内部记录失败节点及邻接面
两次半漂移的散度、累计柱面输运、非输运eta改变量、压力/风/旋转加速度。
同时报告面积加权全域 eta 变化/边界通量、柱与层面输运匹配误差，
并以独立数组差分核对符号、单位和经纬度度量。数值源码插桩应在独立研究副本，
不先改生产共享语义。只保存无私有数组的标量汇总与来源hash。
首次只做dt300一个失败步；预计与已有重放同量级约90–105 s、约2.33 GiB，
这只是预算参考，不是实际新测量。建议单进程CPU、timeout180 s、内存预算4 GiB，
超过即停止，不自动扩容；有判别结果后再决定是否需要另一档。

反证与分叉决策：

- 若独立continuity或非输运分解超原门槛，先定位错误算子；若证实局部符号、
  度量或记账错误，才在原合同内修该处。守恒/正性/回滚与均匀tracer小型CPU回归
  是进入单步复验前提；未证实则退出该补丁路线。
- 若上述恒等式成立，说明这一步按现有参考几何动力确实要求跨过顶控制体边界，
  仍不能证明该动力的物理质量。用同一入态做静止/均匀tracer及无source局部反证，
  检查任意合法正厚状态下离散GCL、源单位和压力静平衡；不以减小原dt通过晋升。
- **有条件的守恒选项**：若只有明确局部动力错误，可最小修该错误；若固定2.5 m
  顶节点本身需要跨越，合并顶控制体须保留总水量与T/S内容、正权重并重算受影响
  的面/垂直输运、源和压力度量及重启语义，属于跨模块设计，先父任务协调。
  本轮不实施。仅重分配库存不约束动力，仍可能再次跨零；以此作为该选项反例。
- 对eta或h执行clip会增加水量并与真实柱通量不符；仅提高容量也不能把负厚变正。
  单独限制出流但不反馈快模压力/动量及柱输运会破坏continuity；均不作为最小修复。

实验成功标准是得到可区分的动力错误或控制体适用域证据，而非让valid变true。
任何修补失败原守恒/正性/回滚门禁即退出；无局部错误则报告设计边界，
不连续堆候选。本轮未新增科学运行、内核、数组artifact或数值资格。
