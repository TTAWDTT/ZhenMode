# 固定参考联系的代数范围与独立检查

本页只讨论固定参考容量、联系输运、标量梯度及列投影。压力重构、自由面移动
库存、时间离散、混合、海冰、精度误差和全球运行均不由这些恒等式认证。
检查在候选实现之后进行，不是盲科学资格评估。

## 定义和前提

固定深度 `0=d0<d1<...<dN`，床深 `0<=H<=dN`。干柱 H=0；湿节点是
`k=0,...,K(H)`，其中 `K=max{k:dk<=H}`。内部边界 `mk=(dk+d(k+1))/2`，
节点 k 的单元从 `a0=0` 或 `ak=m(k-1)` 到内部 `bk=mk` 或末单元 `bK=H`。
厚度 h 是这个区间的长度。干节点没有容量，存储用安全分母 hhat=1；湿点 hhat=h。

每条正面联系左节点 k 和右节点 l。几何权重为两参考区间的交集长度 w，正权重
中深为交集上下界的平均。存储槽 l−k 取 0、+1、−1。经向 i 周期，纬向 j 封闭。
度量必须满足 `dx(i,j)=L*cj`、`A=dx*dy`，其中 L、dy、所有 cj 都为正常数或
正行因子；纬向正面 `cface=(cj+c(j+1))/2`。参考节点体积 `V=A*h`。

合法面通量只能支撑在实际湿联系上，干面、零开口和纬向外墙的通量为零。
每节点的实体通量差

`E(q)=(out_x-in_x)/dx + (out_y-in_y)/(dy*cj)`，`D(q)=E(q)/hhat`。

速度输运 `Tx=w*(uL+uR)/2`、`Ty=w*cface*(vL+vR)/2`；两轴合称 Dvel。
标量差 `delta=phiR-phiL` 保留正面方向，将每个加权差的一半**同号**散到两个
端点，再分别除以 `dx*hhat` 或 `dy*cj*hhat`，定义 Gx、Gy。
内积为 `sum V*a*b`；干点体积为零。R 将列标量广播到各湿节点，
`B(u,v)=sum_k hhat*Dvel(u,v)`，列投影 `P=-A*B*G*R`。

只使用区间比较、有限求和及其重排、实数／有理数代数和矩阵基向量定义；
不能将覆盖、守恒、伴随、对称正性或特殊小网格对角预先当作已知结论。

## C1：三个槽覆盖共同水柱

每柱内部区间首尾相接、内部厚度为正，末区间因 `H>=dK>m(K-1)` 也为正，
故区间内部不重叠且覆盖 `[0,H]`。若 `l>=k+2`，右单元顶界至少是 m(k+1)。
左单元若非末单元，其底界 mk 更浅；若是末单元，`H_L<d(k+1)<m(k+1)`；
若 k=N，则更大的 l 无效。因此遗漏槽均没有正交集；反方向交换左右柱即可。
两柱区间交集的内部恰好覆盖 `[0,min(HL,HR)]`，所以全部槽权重之和等于共同
水深。交换两柱会转置节点对，保持正权重及中深。

## C2：固定库存守恒

湿点 `V/hhat=A`。一条 x 联系对全局 `sum V*D(q)` 的贡献是
`q*(AL/dxL-AR/dxR)=q*(dy-dy)=0`；y 联系是
`q*(AL/(dy*cL)-AR/(dy*cR))=q*(L-L)=0`。逐条相加即得守恒。
自联系和重复的周期正面均按原声明方向计数，不产生例外。固定几何下
`dot(theta)=-D(q)` 因而保持 `sum V*theta`；这只认证声明的参考点值库存。

## C3：平均速度与梯度负伴随

x 联系的散度配对是 `dy*(phiL-phiR)*w*(uL+uR)/2`，梯度配对是其负值，
因为双方 `V/(dx*hhat)=dy`，且差值同号散到双方。y 联系同样把 dy 换成 L、
w 换成 `w*cface`。有限求和后

`sum V*phi*Dvel(u,v) = -sum V*(u*Gx(phi)+v*Gy(phi))`。

## C4：列投影对角

取列基 eC，用已证明的 C3 展开定义，得到
`P_CC=sum_n Vn*(Gx(R eC)_n^2+Gy(R eC)_n^2)`；不是先假设 P 对称或正性。
定义本列 outgoing 和 incoming 权重合计为 p、m，本列正面的接收节点合计
为 t，上一列正面的源节点合计为 r；y 权重包含 cface。

nx>2 时，本列及其前后两列不同。x 系数分别是 `(m-p)/(2*dx*hhat)`、
`-t/(2*dx*hhat_next)`、`r/(2*dx*hhat_prev)`。体积加权平方并求和给出

`A/(4*dx^2)*sum_k[(p-m)^2/hhat+t^2/hhat_next+r^2/hhat_prev]`。

nx=1 时广播差全零；nx=2 时反向正面的联系权重按 C1 转置，广播差互为负值，
每个节点上的两项逐联系相消，因此 x 对角为零，包括不等水深。

y 的前后列若存在就不同，其系数除以各自的 cj，体积加权平方得到

`A/(4*dy^2*cj)*sum_k[(p-m)^2/(hhat*cj)+t^2/(hhat_next*cnext)+r^2/(hhat_prev*cprev)]`。

缺失外墙项的分子为零，ny=1 全部 y 项为零。干列无联系，P 对角为零；
安全分母不会产生体积。两轴平方项相加就是投影预条件对角的代数定义。

## 可复跑的独立精确检查

```sh
python scripts/run_bounded_tests.py --script scripts/check_fixed_partial_contacts.py
```

该脚本从独立校验者的代码归档，仅作命名及格式整理，只用标准库 Fraction，不导入产品几何、
算子或其他验证代码。它检查全部预注册区间、权重、中深、反向联系、两轴通量、
梯度、内积、投影矩阵与对角；还包括边界两侧有理数探针、不均匀节点、干柱、
极浅柱、nx=1/2/3/4 和 ny=1/2/3 的有限组合。输出最终 SUMMARY 必须 PASS，
并且进程退出码为零。两个刻意改错的控制会输出 FAIL 随后被捕获，证明比较器
和假伴随步骤能够失败；不能把这些预期控制误当作未捕获错误。

预注册例子使用深度 0、5、15、30 m。x 例 nx=3、H=3、c=1/2、L=4、dy=3，
u=(1,2,4)、phi=(3,−1,2)，D=(−1/2,3/4,−1/4)、Gx=(−3/4,−1/4,1)，
两配对为 −99/2 与 99/2，P 对角为 9/4。y 例 ny=2、c=(1/2,3/4)、
v=(2,4)、phi=(3,−1)，D=(5/4,−5/6)、Gy=(−5/6,−5/9)，配对为 90 与 −90，
P 对角为 125/96。nx=2、不等床深 3/14 的广播列投影为零。

精确有限检查不是普遍证明；上述区间／有限和推导是另一个证据层。工程审计还
执行了先行反例搜索、两条强制不同的构造路线、两个新上下文怀疑检查、从规范
重新推导的校验者和实际调用链审计，保留每项脚本、资源收据与失败控制。
调用审计发现并修复底层几何标记丢失及不兼容度量被接受的问题。
