# 垂向温度输运小模块迭代

冻结内部波对照已有四次 ZhenMode 16 层温度误差未通过。半幅值的归一化误差近乎不变，32 层误差明显减小。当前垂向示踪通量采用一阶迎风界面值；首个候选只修改这一处重构，验证其是否是主要误差来源。这个假设尚须原生积分检验。

候选 `vertical_tracer_scheme=muscl_nodal_v1` 用物理节点距离计算 minmod 斜率，在内部中点界面给出受相邻浓度范围约束的两侧值，再按实际质量通量选取迎风侧。非均匀网格仿射剖面的界面值可精确重构。湿界面限定斜率，表面/底部通量、实际连续性质量通量、水平输运、步长、EOS、压力及旋转设置保持原样。它仅适用于 `nodal_dual_v1`；界面取值受限不等于完整自由表面时间积分的全局 TVD 证明。

旧默认值仍为 `donor_cell`，冻结选择 JSON、旧报告和原始数据均不改写。新增开发契约绑定原物理契约哈希，使用同一误差和库存阈值。内部波从本轮开始属于开发问题，不能继续用于声称未参与调参的独立验证。
