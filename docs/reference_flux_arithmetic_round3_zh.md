# 积分通量分子与参考浓度的算术修复

前轮1D严格常量控制在21/41节点出现1.110223e-16倾向，超过预声明1e-17；v1/v2/v3均有同一残差。只读核对将它定位为容量除法/倒数乘法及水平补偿装配顺序，旧未通过结果保持OPEN。新柱平均主pilot分数0.05492232392019455高于最佳band/梯形的0.0524039393437639，因此按预声明停止该批余行，不调参数选分；柱mean功能只保留为实验选项。

新增可选 `tracer_flux_arithmetic=integrated_reference_v1`，物理配置保留最佳band/梯形/容量mean。给定全域空间常量r=T的首个节点值，分解T=r+q。水平和垂向通量先按q构造容量积分分子，显式保留 r*(水平质量分子+垂向质量通量差)，将所有分子合并后只除一次容量。即使r来自每次RHS的状态，也不需dr/dt，因为更新的仍是完整T。这是线性通量恒等式，不将q作为新时间状态，不改变实际质量面、节点、容量、物理系数、步长或评分。

质量残差不能省略、不能把常量强制置零：反号Fz但保留原水平质量分子时，非零常量必须给出非零倾向。低阶Euler限幅的辅助水平项也包含这个reference mass residual，保证增量与绝对原式相同。库存仍由真实水平/顶底边界通量收支决定。温标平移在一致不可压质量场保持倾向；若质量残差非零，变化应为−C*mass_residual/h，不宣称坏质量场也温标不变。

原v2/v3受限端点及邻层通量只在参考平移后的浓度上计算，盐度显式绝对零下界平移为minimum−r，温度仍无0°C特界。真实表面边界回报为F0*T0。支持均匀全湿物理表底、至少六节点、unsplit symmetric/closed nodal channel，物理底部质量通量为零；默认保留legacy装配，旧路径可精确回放。

原生数据前声明非零常量1/35/−7的21/41/81节点原1e-17控制、反号质量残差负例、全库存/温标关系、盐度下界及源码registry覆盖。本地135项控制通过。新column模块曾漏入1e613d1的132逐文件manifest：原wheel/build/Git/installed字节已以补充receipt核齐133文件，原manifest/plan/journal不覆盖，后续source registry已补。原完整CI失败或该identity拒绝必须完整保留。
