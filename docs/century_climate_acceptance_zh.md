# 百年可靠性与气候态精度验收

日期：2026-09-29。状态：验收要求，尚非达标报告。

这是完整工业对齐目标中的两项验收，不取代预报、GPU/分布式、完整可微/
可学习能力和工程交付。历史百年结果只对应其原版本与配置；当前新动力
路径的 6000 秒线性参照不能升级为完整模式的百年或气候证据。

## 1. 固定被验收对象

正式实验前记录并冻结：生产入口、代码及环境版本、模式域和极区/海峡
连通、水平网格及垂向层、时间步及快模态子步、浮点精度、实际地形与处理、
状态方程、混合/海冰/源项、完整强迫、初值、自旋升、恢复/同化参数及
重启设置。输入和输出保存哈希、日历、单位和时间坐标/边界。

每项指标的阈值、统计窗口、空间权重、滤波、区域和观测不确定性在正式
运行前注册。阈值须来自用途要求和公平基线，不以新结果倒推通过线。
不同配置分别验收，不声称任意时间步、网格和输入均能可靠运行。
纬度截断域不能直接声称完整全球极区、深水形成或全球环流精度。

## 2. 百年运行与自旋升分开

- 按冻结的交付配置完成 100 个模式年；中断重启可计入同一轨迹，但不能
  悄悄改参、裁剪、过滤或重置漂移。任何保护、恢复和人工修正均计账。
- 自旋升充分性由上层/深海温盐、分海盆库存和环流调整判断，而非仅由
  SST 看起来稳定判断。必要时先完成额外自旋升，再启动验收窗口。
- 重复多年强迫适合自旋升或控制实验；不把它称为真实历史百年重现。
  在历史变化强迫下，正确的物理趋势不应被强行拉成零。

参考 OMIP-2 的公开评估采用六轮 61 年强迫，共 366 年，并评价最后一轮
相应年代的多年统计。这是实验设计参照，不是本项目必须照搬的年数。
[OMIP-2 实验与评估](https://gmd.copernicus.org/articles/13/3643/2020/)

## 3. 必须有实际整步收支，不只看 NaN

水、热、盐分别计算 `库存变化 - 实际离散源汇/边界通量累计`。分母和
绝对单位都报告，不能靠很大的初始库存掩盖持续累计误差。浮力、动力、
势能、外力、物理耗散、混合、限制器、滤波、精度转换和移动网格的功
分开记录；未解释余项不得改名为耗散。全部源项和各子步时层须一致。

输出至少包含：状态范围/异常记录、全年和累计收支、分海盆及
0--700m/700--2000m/2000m--海底温盐与热含量趋势、主要环流和海面高度。
报告人工热误差等效 W/m2、温盐漂移的物理单位及其强迫归因。
首末热盐含量百分比不等于上述预算残差，也不要求有真实源汇的系统
库存恒定。全球平均误差相互抵消不能掩盖局地或深海失败。

稳健性对照至少含时间步减半、合理初值扰动、交付精度与 float64 参照、
连续/多次重启。针对同一窗口比较预算和气候统计；混沌轨迹不能要求
百年逐格逐点一致。硬件实现的差异也需在其所声明配置上验收。

## 4. 气候精度必须与独立数据对照

采用同域、同年代且覆盖充分的多年平均（通常 20--30 年），并计算季节
循环和年际变率。时间平均依据实际日历及样本时间边界，不能让输出
频率或缺失月份改变权重；采样和观测覆盖不足必须报告。

| 对象 | 空间/时间指标 |
| --- | --- |
| SST、SSS | 湿格面积加权偏差/RMSE；季节振幅/相位；年际变率 |
| 三维温盐 | 实际湿体积加权误差；分深度、分海盆和纬向剖面 |
| SSH、混合层 | 定义一致的偏差/RMSE、季节变化和空间分布 |
| 环流/输运 | 在真实覆盖范围内评估关键海流、翻转环流、热输运 |
| 海冰（若交付包含） | 冰浓度/范围、厚度、季节演变及海洋交换预算 |

原始场与预注册统一尺度滤波结果都报告，不后删困难海域或换滤波窗口。
动力海平面的均值基准、混合层定义、温盐类型及单位先统一。
以观测采样和自相关相容的方式估计误差不确定性，不能把所有月和格点
当独立样本。成熟模式对照须固定具体版本、强迫、初始化、恢复方式、
覆盖和评分尺度，不能把多模式平均的优势当成某个单模式的指标。

WOA/Argo、卫星及断面观测可作为参照，但记录原始来源、年代、QC、
重网格与用途。调参/学习和最终验收分离；同化或恢复过的字段应标为
受约束诊断，并另做留出数据/年代的独立检验。OMIP 本身也明确讨论了
用同一盐度恢复目标验收会低估偏差的问题。
[OMIP 参照依赖与指标](https://gmd.copernicus.org/articles/13/3643/2020/)
、[Argo 数据与 QC](https://argo.ucsd.edu/data/)

## 5. 当前可用证据与不能跨越的边界

新配对路径八组真实地形参照（两种地形、32/64 动量、静止/扰动），
每组 100x60 秒，运行和独立最后整步复核通过；九类故意篡改拒绝。
它是冻结线性动力/实际同 Q 库存的参照，不是逐子步独立重放，更不是
完整非线性模式。旧冻结路径的零入射动量降水反例保留为失败证据。
新非线性FV候选已实际推进三维动量/移动自由面及同Q库存，28项直接
验证通过；真实地形八组600秒试验仍总体失败：四组扰动通过整步独立
复核，四组近静止态因体积存储舍入丢失极小海面变化而被严格能量门槛
拒绝。未以放宽门槛或能量重缩放处理。完整浮力/EOS转换及生产迁移
仍未完成；详见[新候选证据](../research/experiments/cgrid_hydrostatic_momentum/nonlinear_dual_review.md)。

当前共享评分器的 v2 修正面积权重、角度窗口和陆地污染，并识别参照
与比较域。旧报告保留旧口径，不能和新分数混比。`T_init` 仍是初值
参照，不是独立观测；现有时间均值和含量百分比仍仅属诊断。
详见[评分协议](benchmark_protocol_zh.md)。这些工具改进不升级模型资格。

正式交付证据应包含：冻结清单、原始百年输出、实际累计预算、漂移与
归因、独立观测评分及不确定性、敏感性/重启报告和可重放的评分命令。
预报另做多起报日期/留出年代的回报，与持续性/气候态和成熟模式对照；
已知未来再分析强迫的实验不能冒称实际业务预报技巧。

## 推进顺序

先闭合完整物理整步并迁移生产入口，再以天/年级实验排除预算错误，
完成充分自旋升、冻结百年/敏感性实验以及同年代独立气候验收。
GPU/分布式、完整梯度与约束学习及交付验收保留在
[完整路线](industrial_alignment_roadmap_zh.md)，不因这些局部结果而缩减。
