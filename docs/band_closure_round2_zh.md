# 第二轮邻近端点层闭合

四配置原生隔离实验及十二行余批全部通过原门槛。三次压力积分对主温度误差仅改善约 0.09%，海面误差却由 0.006691 增至 0.008868，现不作为主候选。新定位表明 v2/梯形的温度误差能量 99.7704% 集中在节点 1 与 N−2，物理首末节点合计约 7.12e−11；需要处理紧邻端点的点值/通量一致性。

新可选 `muscl_band_v3` 保留 v2 的物理端点目标、材料屏障、温标规则、联合 Euler 范围及守恒边界通量。再约束节点 1 与 N−2 的材料倾向：R[k]=−(Hq[k]−q[k]*Hm[k])−0.5*(F[k]+F[k+1])*g[k]，Hm[k]=−(F[k+1]−F[k])/h[k]，其中 Hq 为真实水平 tracer 通量散度，g 为两侧物理 secant 的 minmod。由连续性整理，面目标递推为 f[k+1]=f[k]−h[k]*(R[k]+Hq[k])，底侧倒推同式。F 为真实向下质量通量，不重新投影或校准速度。

内层点位于均匀双面中点，用平均面质量速度近似点速度。minmod 的光滑曲率误差仍存在，不称全模型高阶方法。

新增目标仅在相邻两个质量面均非零时固定为内部修正 pins，任何零质量面优先固定零修正。其他自由区间仍在容量坐标线性连接、最小化容量加权倾向平方和。全列凸组合可能缩小任何目标；必须保留未生效/误差向更深层转移的可能性，不能称无条件精确端点闭合。至少六个均匀全湿物理表/底节点，unsplit legacy。默认及 v1/v2 路径不改。

原生数据前固定仿射材料导数、两个流向、两个步长、温标平移、静止材料屏障、常量、零表面盐度和 Euler 范围/库存控制。新主候选为 v3/梯形；不再试三次压力组合以选分。索引 0 回放 v2/梯形，索引 1 v3 主 pilot，随后预声明主半幅、水平粗主/半、垂向细主/半、null、热风。只有主分数改善、原屏障通过才扩展；先按实测 pilot 时间规划。各原定义、资源限额与冻结参考相同，任何失败保留，不改阈值。

本轮内部波为开发证据，另以先声明再冻结的未用于修订的数值数据作窄范围空间检查，不当作全海洋独立验证。每个冻结源码独立包和原始数据身份明确，先前 v2 压力阶段与失败原封不动。完整 pytest/MMS CI 必须跑新生产提交；PR69 保持草稿不合并。
