# 有限海面高度的密度压力项

在相同热成风初态上，新选项将海底动态压力的最大空间差从 0.009961645 Pa
降到 5.713×10⁻¹² Pa。实际 GPU 积分的海面相对误差降低约 0.114%，密度相关
温度误差几乎不变；八组驻波／旋转波的原生数组与上一轮完全相同。因此，本轮
补齐了一个压力定义差异，粗网格剩余误差的主因仍需诊断。原默认处理保留。

## 接续的证据

PR60、PR61、PR62 分别处理墙边速度、成对压力／连续性模板和示踪物乘积通量。
PR62 的密度相关温度误差约为 2.14648×10⁻⁵ °C，已经接近总温度误差。随后三组
GPU 开发探针改变了热成风网格：ny=64、nz=16 的该误差为 1.103109×10⁻⁵ °C；
ny=32、nz=32／64 的值为 2.045469／2.020049×10⁻⁵ °C。水平加密的改善较大，
垂向加密的改善较小。这些探针改变了网格，单独保存，未进入原有标准评分。

原压力定义将密度异常从固定 z=0 面积分到各节点，再加上 ρ₀gη。热成风解析初态
则采用积分至实际海面 z=η 的压力定义，两者相差 η 与密度异常的乘积项。
[MOM6 方程说明](https://mom6.readthedocs.io/en/main/api/generated/pages/Specifics.html)
区分静止参考面 z=0 和实际海面 z=η；该说明提供方程背景，不验证本实现。

## 单模块修改

`hydrostatic_surface_scheme='linear_density'` 在已限定的线性 EOS 通道中，使用
顶部两个节点的密度异常作局部线性延拓，并增加

```text
ΔP = g × [ρ′(0) η + ½ (∂ρ′/∂z)|₀ η²]。
```

有符号积分适用于正、负海面位移。三维压力和深度平均密度力使用同一个定义；
提取平均密度力时保留实际 η，只有 ρ₀gη 留给原外模压力算子。非线性阶段扣除
这个平均力，外模阶段再施加一次，以避免遗漏或重复计入。

这项选择仅开放给全湿平底笛卡尔、静态节点容量、对称外模、成对四阶压力／连续性、
线性 EOS、顶节点 z=0 的无混合通道，继承原有底拖曳、极区、投影和海冰限制。
连续性仍是线性自由面形式；顶部密度延拓是局部重建假设，没有增加物理水柱容量。
密度负载沿用既有源时相读取，因此尚未建立完整非线性自由面、整体能量闭合或
新增耦合项的时间精度资格。所有旧选项、初态、评分格点、权重和阈值均保留。

## 压力检查

独立的多项式积分控制覆盖正、负、零 η，以及零、常量、线性密度异常。
压力绝对容差在候选积分前规定为 2×10⁻¹¹ Pa，错误符号和遗漏负载均被检查识别。
平均力的解析模态及完整 L／N／L 响应检查其施加次数，错误的零 η 提取和双倍施加
均无法满足既定容差。严格重启检查覆盖六个状态字段，并拒绝另一种压力定义。

对 GPU 实际保存的初态调用当前生产压力算子，得到如下 CPU 诊断。连续参考直接
积分线性密度律；它与本模型共享 EOS 和方程假设，属于开发一致性控制。

| 初态指标 | 原参考面压力 | 新密度负载 |
| --- | ---: | ---: |
| 海底动态压力最大空间差，Pa | 0.009961644507 | 5.7128×10⁻¹² |
| 与连续压力积分的最大差，Pa | 0.01005826728 | 2.8706×10⁻¹² |
| 压力／科氏合力 RMS，m/s² | 3.560008972×10⁻⁹ | 3.546686112×10⁻⁹ |

海底压力一致性改善后，初始合力残差仍在相同量级，这与该修正不是粗网格主导误差
的判断一致。这里的动态压力省去了固定参考密度的 −ρ₀gz 项；平底处该项是常量，
不影响表中的海底空间差。

## 实际对照

本轮完成十次 float64 CUDA 原生运行：五组周期驻波、三级旋转波、一次热成风，
以及一次同包旧热成风控制。全部通过原有筛选。逐数组核对确认，前八组与 PR62
完全相同；同包旧热成风控制也完整复现 PR62 的原生数组，新旧初态六个数组相同。

| 热成风指标 | PR62 处理 | 新密度负载 |

| 海面相对误差 | 0.0006686850872 | 0.0006679224071 |
| u 相对误差 | 0.0003082176199 | 0.0003082137655 |
| v 相对误差 | 0.0001969915232 | 0.0001969874851 |
| 温度误差，°C | 0.00002174986994 | 0.00002174985565 |

按相同体积和时间权重计算，B=T−(0.779/0.205)(S−35) 的误差从
2.146478353×10⁻⁵ 变为 2.146477693×10⁻⁵ °C，密度中性温度等效误差从
3.509973035×10⁻⁶ 变为 3.509924827×10⁻⁶ °C。场分解包含交叉项，并复合成
原温度误差；它不构成独立的因果误差份额。整体变化很小，不能把压力积分一致性
改善描述成分层误差已经解决。
