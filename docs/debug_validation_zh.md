## 修复了什么

| 缺陷 | 修复与回归证据 |
| --- | --- |
| 混合层只改变表层热容量，没有加热其他节点 | 按混合层与湿节点厚度的交叠分配热量。5 m 表层、20 m 混合层、100 W/m² 输入不再只留下 25 W/m²；`test_surface_energy.py` 验证全湿、浅水、空间变深、掩膜与过深混合层。 |
| 动态海冰重复应用表面热通量，完全融化时丢失余热、过量淡化 | 动力步中关掉这一路热源，由可选的一阶表面算子应用一次；按水显热减冰潜热更新相态，实际冰厚变化决定盐源。验证生冰、已有冰生长/融化、完全融化和整步单次加热。 |
| 海冰没有写进检查点 | 保存全部六个状态字段；重启检查网格尺寸与字段形状。动态海冰拒绝缺少冰厚的旧检查点，非海冰模式仍可读取；逐字段验证两步连续积分与存盘重启相同。 |
| `salt_content_kg` 把 PSU 当成 kg/kg | 用 `S/1000` 计算名义盐质量，新结果标记 `diagnostics_schema_version=2`、`salt_content_units="kg"`。摘要读取未标记的旧结果时换算单位；相对盐漂移百分比不受常数换算影响。 |
| 所谓海冰“热残差”未扣除外部热输入 | 单独报告水冰焓变化；没有累计 `surface_heat_input_J` 时残差为 `null`，不再伪称闭合。仅在提供这项输入时计算差值。 |
| TVD/MUSCL 坡度跨南北封闭墙、读取陆地哨兵 | 纬向使用边缘延拓，经向保持周期；坡度只使用湿邻点。修改北墙值不影响南墙近邻输运，修改陆地值不影响相邻湿面重构。 |
| 沿岸增强扩散采用 `k(x,y)*lap(T)`，不守恒 | 启用增强带时，改为湿面系数平均和球面通量散度，关闭南北通量；验证有陆地、纬向温差和空间变系数时的加权热收支。未启用时保留旧常系数路径。 |
| 缺失/非有限预算、穿零后更大偏差可能过门禁 | 指标缺失、NaN/Inf、覆盖不全均拒绝；墙区偏差比较绝对值，百分比漂移起点为零或数据无效时不再报零。 |
| 外部评分忽略 CF 时间单位，两个评分入口重复 | 统一 NetCDF 读取与评分，转换秒/小时/天，尊重日历，拒绝无单位及非递增时间；验证 MOM6 入口与通用入口一致，关闭陆地填充时仍正确转置。 |
| 外部场只覆盖极少参考湿点也可能 PASS | 报告参考湿点覆盖率；PASS 要求参考海洋完整覆盖且 SST 误差有限。它不表示气候误差达标，更不表示整个外部模式数值稳定。 |
| wheel 漏装驱动依赖 | 补齐模块清单；AST 回归检查本地导入闭包，并在仓库之外安装 wheel，用隔离 Python 启动 CLI `--help`。 |

## 积分验证的定义

独立验证入口：

```bash
python scripts/verify_debug_integration.py --days 30 --out results/debug_verification/30d.json
```

四组：基线、20 m 混合层、20 m 混合层加动态海冰、沿岸增强扩散。
全部读取真实 ETOPO2022，初值、风和气温是解析合成场，**不是 WOA/NCEP**。
这不是生产气候态或预报技巧检验。

- 网格 2°，180 × 65 × 14，纬度范围 ±65°；地形平滑 80 次，
  `min_depth=500 m` 会屏蔽更浅海域。
- 外步 600 s，正压子步 50 s，mode split、scan、2D CFL 黏性子循环；
  保守垂向扩散、局地对流、输运速度投影和 TVD/MUSCL 均开启。
- `nu_h=2e6 m²/s`，`nu_bi=kappa_bi=kappa_gm=kappa_redi=0`，
  `kappa_v=1e-6 m²/s`、`kappa_conv=0.01 m²/s`；沿岸组额外
  `kappa_h=500 m²/s`，作用于距陆地三格以内的海域。
- float32；每一步检查全部状态有限性、水平速度绝对值和海面高度，
  保持原来的 10 m/s、15 m 上限。每 6 小时存一份摘要及区间峰值。
- JSON 保存运行参数、源码 SHA256、地形 SHA256、起点 Git 状态与设备。
  编译时间计入墙钟时间，结果不能当作 GPU 性能基准。

## 结论边界与后续

1. 守恒回归针对独立表面/扩散算子，并非证明全模式预算闭合。浮力、
   强迫、恢复项和其他数值操作仍需单独计账；主驱动尚未记录累计表面热输入。
2. 动态海冰是可选的一阶算子分裂原型，没有海冰运动、混合层夹卷、
   完整垂向热力学或全混合层相态平衡。非相变点的梯度有回归验证，
   不等于相变处光滑，也不等于长积分梯度可靠。
3. 常系数水平扩散的历史路径未替换；本轮沿岸通量守恒证明不能外推到
   全部算子。`fct_adv` 仍是局地 TVD/MUSCL，不是完整多维 Zalesak FCT。
4. 历史 A2 平滑继续保持五格窗口以免静默改变协议；不同分辨率下并非
   相同的物理尺度。跨分辨率比较必须先统一物理滤波定义。
5. 旧海冰检查点丢失的冰厚无法恢复；不要填零继续作为同一次实验。
   旧混合层/海冰实验的气候分数是修复前证据，重要结论需重新积分。
6. 本机只有地形文件，没有完整 WOA/NCEP 输入。下一层是具备真实输入后
   按固定生产配置重跑 30/365 天，随后才检验百年漂移、气候态误差与
   预报技巧。任何短期有限性 PASS 都不等于这些指标已经达标。
