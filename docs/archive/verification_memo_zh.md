## 一、一句话总结

- 求解器的**算子精度与理想化动力学**经得起对抗性审查（解析解/已知解全部命中）；
- 模型输出的**大尺度风驱海面形态符号正确**（SSH 高值落在负风切变涡度带下，符合 Sverdrup 平衡）；
- 但模型的**正压海面变化仅约 4 毫米**，而观测 SLA 被**中尺度涡**主导（约 26 厘米），
  两者直接对比必然是噪声主导 —— **T3-1 实测相关为 -0.386，如实记为 FAIL**。

## 三、Tier-2 的定论数字（两根支柱）

> 附注：备忘里出现过的 "T3-2" 是占位编号，无对应测试；Tier-2 的两根支柱为 T2-1 与 T2-2。

### T2-1 — 惯性振荡频率（`bench_t2_inertial.py`）

在 f 平面上，均匀速度 + 平海面 + 均匀密度时只有 Coriolis 项起作用，
模型必须以解析频率 `f0` 旋转速度矢量。北半球为顺时针旋转。

```
  f_theory       = 8.3651534630e-05
  |f_measured|   = 8.3709891604e-05
  rel_err        = 6.976e-04   (0.07%)   -> PASS (<1e-3)
  amp_drift      = 3.457e-04            -> PASS (<1e-3)
```

### T2-2 — 地转调整（`bench_t2_geostrophic.py`，12 天确认运行）

高斯 SSH 隆起从静止释放，调整到地转平衡。内部条带应满足
`f0·v = +g·∂η/∂x`、`f0·u = −g·∂η/∂y`。活跃区 corr≥0.95、残差比 ≤0.15。

**最终数字（`logs/t2_geostrophic_final.log`，定论）：**
```
  活跃区 (7912 点):
    velocity RMS           = 0.1840 m/s
    ageostrophic resid RMS = 0.0096 m/s
    residual ratio         = 0.0519
    geostrophic corr       = 0.9984          -> PASS (>=0.95)
  [全区条带: vel_rms=0.1345 res_rms=0.0078 ratio=0.058 corr=+0.998]
  eta 峰值: 0.796 m → 0.503 m（12 天单调衰减，重力波被辐射出去）
  边缘海绵: 开启 (tau=3600s, 外缘 15% 带)
```

**为什么需要边缘海绵（关键物理洞见）：**
- 生产配置 `H_sw=4000m` → 变形半径 `LR≈2367km` > 周期域（~1166×1423 km），
  流场根本分不出"平衡分量"；
- 变浅 `H_sw=200m`（`LR≈530km` 落在域内）后速度能发展，但**没有海绵时，
  周期边界会无限回收发射出的惯性-重力波**（残差比一直停在 ~2.8，eta 峰值非单调振荡）；
- 在**测试层**加入牛顿型边缘海绵（生产求解器未动），让内部真正辐射并达到平衡 ——
  这是有界/周期域上标准的波辐射处理手段。
- 结果：corr 0.9984、ratio 0.052，**PASS**。

## 四、Tier-3 的真实数据对比：如实失败 + 诊断

### 运行参数

- 30 天预热（8640 步，dt=300s）
- 真实 NCEP/NCAR R1 **2023-01 月均风**（`real_wind_forcing`）
- 对比 NOAA CoastWatch `nesdisSSH1day` 观测 SLA（经 <50km 平滑 + 去均值）

### 实测数字（`logs/t3_realdata.log`）

```
  空间异常相关 corr : -0.386
  RMS 异常差 (RMSE) : 0.2599 m
  模型 std / 观测 std: 0.0040 / 0.2584 m
  FAIL: corr -0.386 > 0.25   （证据线未达）
```

### 诊断结论

1. **模型的正压海面设置只有约 4mm**（std=0.004m）。
   对正压层来说，经双调和粘性闭合抑制后，这个幅度物理上合理。
2. **模型大尺度形态的符号是对的**：SSH 高值落在中纬度**负风切变涡度**带
   （副热带环流内部）下方，符合 Sverdrup 平衡 —— 说明**不是风向/环流方向反了**。
3. **观测 SLA 被斜压中尺度涡主导**（std≈26cm；即使 0.5° 平滑后，
   各纬度带内标准差仍达 0.2–0.29m）。正压模型**原理上无法**产生这种结构/幅度。
4. 因此相关是**噪声主导**：把 4mm 平滑环流与 26cm 涡场去均值后做相关，
   测量的是"模型根本没有的涡结构"的错位，负号基本无物理意义。
5. 预注册的证据线 corr>0.25 **没有为凑 PASS 而改标尺** —— 如实记录为 **FAIL**。

**可直接展示给审稿人的一句话：**
> 模型对其能表现的分量（大尺度风驱正压海面）给出符号正确的响应；
> 它失败于其原理上不能表现的分量（斜压中尺度涡）。这被明确记录为模型能力的边界，
> 而非求解器的数值误差。

### 可选的合法后续（未运行，需先定标尺）

更强的空间平滑（≈2–3°，数百公里）可把"环流尺度的风驱海面"从涡场中隔离出来，
对"这个分量"做更公平的测试。但**任何此类标尺必须在重跑之前固定**（守住 R1/R4 红线），
不能先看结果再改判断标准。
