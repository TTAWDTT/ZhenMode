## 2. 范围与非目标

### 必须处理

1. 温盐节点权重、正压垂向积分、湿面开放与可表示水柱厚度不一致。
2. 正压海面更新的子步平均输运没有匹配温盐的实际输运时层。
3. 当前部分动量过程两次使用旧速度，不能作为通用二阶 RK2。
4. 原数值耗散、滤波、恢复和舍入的影响缺少清晰归因；准确性声明需修正。
5. 改动后的完整步预算、初始化/重启兼容性、真实地形稳定性与敏感性。

### 本阶段不默认实施

- 整体迁移 C-grid、改换所有状态为层平均库存或接入新非线性核心。
- 新状态方程、新混合参数化、完整动态海冰、极区拓扑或海峡参数化开发。
- 为通过测试调大黏性、加恢复、删困难海域、放宽门槛或清零预算残差。
- 只为节约计算而静默降低验收分辨率、换 dtype 或更改强迫。
- 以 GPU 加速、梯度可算或测试总数代替正确性与应用验收。

现有物理过程若因几何改动受影响，必须复核对应依赖；不是一律跳过。
不能把未测试的 GM/Redi、对流或海冰开关纳入“全部功能可靠”的声明。

## 3. 第一项决策：明确物理与库存合同

在修改公式之前，写清交付版本采用什么近似。不能既保持全部旧状态语义，
又宣称完整真实变体积库存已经严格闭合。

### 优先评估：保留线性自由面算法家族

明确参考水柱厚度 `H_ref(x,y)`、节点控制体、湿面、顶面修正、淡水/盐源约定，
并统一其离散时层。允许有声明的台阶地形近似，不要求为“有限体积”标签改网格。
深于最深节点的水柱、浅底节点、薄底控制体与最小深度筛选必须有明确政策，
不能把原始 ETOPO 深度与实际离散水柱默认视为相同。

参考域库存、线性化近似项和实际海面位移库存分别诊断。
近似误差须从所选方程独立推导、在运行前定义；不能将事后剩余量命名为近似项。
已解释的近似误差仍需评估大小与累计影响，不自动视为可接受。

### 何时升级局部自由面/体积表示

如果应用明确要求真实淡水体积变化、实际变厚度热盐库存严格一致，
或保留线性近似的误差超出预定用途门槛，需增加一致的厚度/库存表达。
先评估能否在原核心内局部升级；这不自动要求更换水平交错网格或全动量方法。
若不得不改变状态与重启合同，先报告扩大范围和新的工期，不静默进入重写。

参考：[MITgcm 自由面与厚度/示踪剂时层](https://mitgcm.readthedocs.io/en/latest/algorithm/nonlinear-freesurf.html)
；[MOM6 快慢输运匹配](https://mom6.readthedocs.io/en/main/api/generated/pages/Barotropic_Baroclinic_Coupling.html)。
它们提供设计约束，不证明本项目任何候选已经达标。

## 4. 实施工作包与里程碑

### M0：冻结基线与验收定义（第 1 天）

- 核对 H/R、conda 环境、地形、历史输入和配置；缺失项单列，不阻止合成控制实验。
- 确定第一阶段实际支持的域、分辨率、物理开关、精度、外步与正压子步。
  主验收至少包括 mode split；单体路径保留针对性回归，不默默退役。
- 运行 R 的小网格/真实地形短基准，保存实际完整步预算与失败，而非只看端点。
- 冻结上述物理/库存合同、误差尺度、比较窗口与每项判据，测实际吞吐。

产物：一份运行清单、R 的原始对照结果、待取输入列表、确认或调整后的工期。
M0 未完成，不作“修复后更可靠”的比较声明。

### M1：统一静态湿几何与垂向积分（第 1–3 天）

- 使节点控制体权重与声明的参考水柱一致，统一正压平均和逐层列输运的定义。
- 使用一致的开放面厚度构造输运；变深度情况下，不用简单的 `H_cell*div(u)`
  冒充守恒的 `div(H_face*u_face)`。
- 检查压力/散度配对、三维湿面和正压回传后的积分关系。
- 同步复核扩散、对流、表面热/风输入、底拖曳及 CFL 对新权重的依赖。
  不只改 `dz_node` 而保留其他旧归一化。

先过全湿 50 m、垂向剪切、浅底台阶、干层哨兵和封闭边界测试，再上真实地形。
诊断库存必须来自所选几何，而非为了结果好看临时换一套权重。

### M2：匹配实际快慢模态输运与自由面（第 2–4 天）

- 累计真正推动 eta 的正压子步面输运，明确 OLD/NEW 速度的使用顺序。
- 让温盐的实际阶段/子步输运与该平均量按所选合同匹配；不能仅把最终速度
  传给已经结束的温盐更新，或在末尾补一个 `eta*T_surface` 诊断。
- 必要时调整 `_step_impl` 的阶段顺序，但仍在原核心内逐项验证。
- 复核压力、风、Coriolis、底拖曳的快慢分配，排除重复计入或遗漏。
- 滤波/极盖之后重新检查实际输运与库存，记录其数值变化。

产物：局部连续方程、恒定 tracer 与层积分匹配的独立证据，实际整步账本。
投影收敛不能替代这些条件；不清顶面或扣全局均值来伪造闭合。

### M3：修核时间推进、耗散与工程兼容（第 3–5 天）

- 对已复现的一阶动量过程设计局部修法，保留内波压力/温盐耦合的稳定性要求。
  不把原双求值机械替换成 Heun 后就宣布整个模式二阶。
- 使用解析拖曳、非线性平流、旋转和线性重力波分别测时间误差、相位与耗散。
  若二阶目标未通过，明确记录该项未完成，不继续使用笼统 RK2 声明。
- 现有稳定化不以“非物理”名义一并删除；区分物理耗散、数值耗散和未解释余项。
- 初始化、检查点、有效参数及预算累计同步版本化。旧节点样本不得直接改名成
  层平均；若物理解释变化，必须显式迁移，不能作为原轨迹无缝续跑。
- 对改动路径做局部 JVP/有限差分与 VJP 一致性检查；不据此声称百年伴随可靠。

产物：时间精度/稳定性表、变化说明、连续与重启对照、针对性回归。

### M4：完整步与积分验收（第 4–7 天，算力依赖）

按第 5 节矩阵运行，不通过时保存首个失败步和最后接受状态。
先验证主要支持配置，再逐项启用已声明交付的物理开关，不一次引入全部变化。
在 M1/M2/M4 边界做完整回归；小补丁先跑相关测试，不每次重复整套验证。

产物：可重放的 C/R 对照、真实地形积分结果、预算/敏感性/重启报告、支持边界。
若 30 天验收或必要配置尚未完成，交付只能标为“修复候选”，不能称验收完成。

## 5. 验证矩阵与通过条件

| 层级 | 样例/时长 | 主要检查 | 能证明的范围 |
| --- | --- | --- | --- |
| 算子 | 全湿、陆地、底台阶、剪切与哨兵 | 几何、湿面、伴随/守恒恒等式与源归一化 | 对应算子与合同 |
| 完整步 | 静止分层、扰动、常量 tracer、热/盐源 | 实际时层、库存、压力功、源汇单次计入 | 完整离散步；非长期气候 |
| 理想轨迹 | 固定窗口、三档 dt | 时间误差、波速/相位、耗散与界限 | 声明过程的稳定性/阶数 |
| 真实地形压力测试 | 1 天 → 7 天 → 30 天 | 每步有限性与峰值、实际预算、不同地形/精度 | 明确配置下的短期证据 |
| 真实输入试运行 | 输入齐备后 30 天 → 1 年 | WOA/强迫适配、季节变化、漂移与参考评分 | 生产试运行；另计工期 |
| 长期/预报 | 后续单独立项验收 | 自旋升、百年、独立观测及留出回报 | 气候与预报能力，不能由上层代替 |

真实地形压力测试可以使用合成初值与强迫，但必须显著标注；不能叫真实气候检验。
生产声明的目标网格必须实际测试，2°成功不替代1°资格。对照保持相同物理域；
旧2°/1°夹具边缘不同，不能直接作为同域空间收敛结果。

### 判据如何冻结

以下为拟采用原则；M0 在正式结果产生前记录每个样例的单位、尺度与具体容差。
不能在看到结果之后只修改门槛。若协议确需修订，保留原结果和修订理由并重跑。

1. **恒等式：** 独立 NumPy/解析计算几何和实际面输运，不只调用同一个 helper
   当作期望值。float64 相容性测试拟以 `1e-11` 相对尺度为起点；零/近零量另用
   事先推导的有单位绝对舍入下限。float32 不机械沿用 float64 容差。
2. **常量保持：** 在满足所选连续方程且无 tracer 源的受控输运中，拟采用
   float64 `max|C-C0| <= 1e-12*(1+max|C0|)`；移动几何须同时检查库存与浓度。
3. **时间精度：** 若声明二阶，三档 dt 在预定渐近区连续两次误差缩减比应至少
   3.3，同时核对解析/更细参照及误差绝对值。空间 MMS 通过不能替代时间阶数。
4. **稳定性：** 保留已有逐步有限性、10 m/s 速度与15 m海面停止线，不调参绕过。
   通过只表示未触发停止；解析波、静止态和气候物理误差仍需另检。
5. **预算：** 分开报告参考域离散收支、明确线性化近似、实际物理库存与数值误差。
   不把顶面内部输运改叫外部热源，也不把阶段变化相加当作物理闭合。
6. **累计：** 同时报有符号/绝对累计、每步与分区域/深度误差，以及 m³、kg、J
   和等效热误差 W/m²。不能用巨大初始库存作分母掩盖持续误差；容差必须兼顾
   状态更新舍入与用途允许的累计误差。
7. **敏感性/重启：** 至少比较 dt 减半、支持的32/64位精度与连续/多次重启。
   同设备同配置的短期重启需匹配状态、强迫相位和累计预算；跨硬件按预定义
   误差合同比较，不要求长期混沌轨迹逐位相同。

至少保留几类负对照：错误垂向权重、用末态替代平均输运、遗漏源/重复源、
错湿面或错重启元数据，应能被对应检查检出。不得仅凭新测试数量报告完成度。

## 6. 工期、依赖与止损机制

**3–7 个工作日是第一阶段的规划区间，不是工业级全部完成的承诺。**
M0 之后给出实际计算预算；M1 之后复核是否需要扩大状态/自由面合同。
“工作日”不表示本会话结束后会自动在后台工作。

| 风险/依赖 | 应对 |
| --- | --- |
| 历史百年代码或输入缺失 | 先冻结 R 并做可复现控制实验；H 的复现单列待办，不编造成功/失败 |

| 线性近似不满足实际库存目标 | 显式提出局部变厚度升级，不直接切到 N；更新范围、重启合同与工期 |

| 新方案改善预算但恶化解或性能 | 同输入比较误差与成本，允许拒绝候选；不把守恒视为准确性的充分条件 |

一个工作包若连续尝试仍没有新的可验证进展，应提交具体瓶颈与可选路径，

不以“更漂亮的严格恒等式”无限追逐远低于应用尺度的近零舍入项。
已识别的小误差也不能直接忽略：需独立量化来源、累计和物理影响。

每个里程碑反馈四项：完成了什么、实际通过/失败、影响哪些声明、下一项是什么。
账本只维护本方案、一份验收汇总与运行清单；原始日志/失败数据保留，不继续
为每个小修复扩展一条新的研究主线。

## 8. 后续百年、气候与预报阶段

第一阶段完成后，获取完整真实输入，固定用途和指标，测目标硬件吞吐，
再安排真实强迫年级实验、充分自旋升、冻结百年控制/敏感性运行。
计算时间按目标配置实测模式日/墙钟日估计，并计入编译、I/O 与重启成本。
CPU 合成压力测试不能作为 GPU 交付性能。
