# 第二轮：端点点值与守恒通量闭合

上一轮受限重构主网格温度 RMS 为 6.18991422672402e−6 °C，但仍高于两个参考模型。只读诊断发现首末各两层贡献 99.541% 的温度误差能量；32 节点也是同一区域主导。因此先试端点闭合，不同时修改压力积分、水平输运、时间方案、EOS、网格或阈值。

新候选 `vertical_tracer_scheme=muscl_endpoint_v2` 保留上一轮 limited 界面重构，增加受约束的守恒数值通量修正。向下坐标下，未限幅顶端目标内部通量为 F1*q0+h0*F0*q_d(top)，底端为 F(N−1)*qN。内部修正按容量坐标分段线性连接，这最小化各连通段内的容量加权倾向平方和；修正的物理顶/底通量为零。实际质量通量为零的内部界面也强制修正为零，不通过材料屏障，也不改变未连通层。

单列凸组合限制修正后的 Euler 状态在当前列、未修正状态及表面入流预测的联合范围内。入流边界允许 q0−dt_sub*F0*q_d 这项局部特征线预测，避免列最大值机械取消真实入流闭合；盐度使用显式零下界，温度不以 0 °C 为特殊界限，并检查改变温标零点后的不变性。该限制不能修复低阶状态原有的负值或超调，也不认证全耦合 RK2 的任意 CFL 正性/TVD。

当端点相邻内部质量界面关闭，材料屏障优先，端点目标不强制执行；其他层的凸组合约束也可能减小修正。因此它是条件性的全段数值一致性修正，不是所有界面均可写成质量通量乘局部有界 donor 的物理模型。首版只接受均匀、全湿、顶节点 z=0、底节点等于真实平底、unsplit legacy、至少四节点。旧 donor_cell 和 muscl_nodal_v1 数值路径保留。

运行前控制检查闭端点仿射真值、常量、静止流、开放表面入流、非负盐度外推、温标平移不变性、材料屏障、未连通区域、凸组合范围及库存相消。第一轮 JAX 反向扫描负轴触发运行错误，保留失败记录并改用非负轴；不是放宽数值判据。独立审查指出的旧表面 limiter 反例和静止界面传输反例均属于开发控制。代码冻结后另声明的非线性流函数染料控制只执行一次，不据其结果调这轮算法。

内部波已经属于开发问题，不能再称作未参与调参的 holdout。先运行上一轮已验收主方案回放与新候选主方案各一次；根据当前机器实测耗时，才扩展预声明的六组网格/幅值、两个 null、热风回归及其余必要对照。每次 1 CPU、600 s、4 GiB 采样进程组 RSS，原目录和失败记录不覆盖。若新候选无改善或数值/保留控制不通过，报告 OPEN 并保存结果，不提高阈值，不通过挑选单项宣布 SOTA。
