原门槛与独立观察者

NumPy 观察者不导入模型或 JAX，也不调用生产者的真值函数。它从原 native 数组和实际参数构造诊断 h=dz_node（顶层加实际 η），用 h×area 做温盐、速度与密度空间加权，η 用 area；每个时刻先归一化空间误差，再做时间梯形平均，RMS 最后开方。温盐 L1 分母为解析扰动 |Q| 的同权积分，盐度另乘 α/β；不用 15 ℃／35 PSU 背景稀释误差。

预声明门槛保持：T RMS≤0.008 ℃、S RMS≤0.002105263157894737 PSU；u/v/η/ρ 的声明尺度归一化 RMS≤0.1，且每个输出的密度归一化 RMS≤0.1；诊断体积相对漂移≤10⁻¹⁰，温盐库存≤10⁻⁸；真正零剪切控制各场最大绝对漂移≤5×10⁻¹¹（η/h 为 m，u/v 为 m/s，T 为 ℃，S 为 PSU）；孤立常量 T/S 源 RHS 分别≤10⁻¹⁷ ℃/s、10⁻¹⁷ PSU/s。最细网格温盐 L1≤0.05，相邻加密比≥1.25。还检查 finite、正容量、T≥−1.8 ℃、S≥0，以及初始场、EOS 和异常压力的原绝对 Pa 算术预算。没有事后改门槛。

纯解析／源码／恶意输入控制一次执行 176 项通过；每个初始化独立审计通过后，四个原件 SHA 才许可测时和原生计算。五个科学审计的观察数依次为 220/220/222/177/183，带真假断言数为 212/212/214/171/177；观察数不等同于断言数。原退出码、资源、逐项 journal 和 verdict 全保留。
