三种模式的 eta 和深度平均 u 误差随这组联合空间／时间加密下降。Oceananigans 的 eta 和相位误差在三个分辨率下均较小；细网格 ZhenMode 的深度平均 u、振幅和能量指标较好。粗网格 MOM6 的能量变化为 2.651093%，超过原有 2% 阈值；另外八组通过已有工程筛选。该阈值并非通用模式资格标准。横向速度分量 v 的泄漏指标也在 JSON 中保存，九组均通过其已有阈值。

这些结果比较指定配置在一个平底、无旋转、均匀温盐波上的响应。联合加密不能单独确定空间或时间收敛阶，也没有验证其他动力、海岸、分层或气候问题。解析参考为线性小振幅波，实际模式推进完整非线性方程，A/H=1e-4。

## 原生离散及执行身份

- ZhenMode：原有完整 FD 工厂和 legacy 时间步，点值、固定 nodal dual 水柱容量。
- MOM6：固定 f49a00096df607b48354603e2398e14e189fd62e，C 网格、四个移动层、无 ALE 重映射；原生 split 时间方案的实际参数在运行后核查。
- Oceananigans：固定 0.113.5 / 1e8587b17171b0bba5bc6728118c3dbbd3c8acf6，CUDA.jl 5.9.1、Julia 1.11.9，HydrostaticFreeSurfaceModel、SplitRungeKutta3、z-star。请求 8 个自由表面子步，原生时间平均核对应实际 FixedSubstepNumber(5)，保持作者核设置。T/S 浮力异常与两个非零物理温盐见证共四个标量。

C 网格 eta 以精确格均值初始化并与解析格积分比较；FD eta 与解析点值比较，速度均在原生位置评分。Oceananigans 层厚从实际演化的 z-star 网格导出；其表面位移伸缩全部层，FD 诊断和 MOM6 则作用于顶层。坐标边界检查采用已存在的原生位置检查 1e-9 m 容差，接受约 6e-13 m 的坐标舍入。v0 评分和工程阈值保持原值。

九组科学运行采用 ZhenMode 提交 b2f558d125b21caeb5cc9e64033c0f255c7d7838，细网格三方运行来自在仓库外安装的 wheel。后续 review 修复提交 25c22db9aad70536a54900c2bd52f2dbebabc1e7 加强真实解释器／JAX 身份、模型布局、调用方 GPU 选择、优化 Python 参数门禁及提交来源校验；核心积分器、配置、评分公式未改。修复后的 wheel 在仓库外完成三方粗网格复跑；各模型九项指标和失败列表均与修复前精确一致。原九组 ZhenMode 收据的 `executable_sha256` 实际是积分代码文件哈希，原始记录保留；真实 Python/JAX 和 CUDA 包身份从修复后的粗网格运行开始记录，不能追溯为旧收据补证。

本轮记录各模型准备、积分及总墙钟时间，但设备、编译策略和标量数不同，尚未做共同误差约束下的成本比较。当前不提供速度排名。MOM6 缓存二进制可核对实际哈希；其历史完整源到二进制构建收据仍缺失。
