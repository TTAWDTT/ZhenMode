‘未被全面超过’指没有另一配置在五项误差上都不大于它，并且至少一项更小（通常称为Pareto前沿）。u/v分别是两个水平速度分量，T/S分别是温度/盐度。

ZhenMode 的两条 dt=12.5 s、joint_shear 配置说明了评分取舍：索引9用中心示踪方案，相对索引8的乘积通量，海面误差只降低约2.844e-05%，温度误差增加约55.83%，盐度误差为约7.375倍。两行的折中分数都受海面项控制；分数最低不能解读为温盐更好或统一推荐。完整向量与各项最低行应一起看。
