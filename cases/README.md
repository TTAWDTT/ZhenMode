# 共同物理问题

每个 YAML 固定区域、海深来源、初始场、边界、强迫、模拟时长、输出间隔及网格要求。正式预设在 `configs/zhenmode/presets/`，不能覆盖这些共同条件。当前输出适配要求共享网格，没有自动重网格。

| Case ID | 用途 | 输入状态 |
| --- | --- | --- |
| `global-045deg-seasonal-365d` | 既有 0.45°、65° 纬度边界、年度空气及季节风 365 天问题 | 外部缓存 SHA256 待补；历史 raw/A2 身份不变 |
| `global-050deg-wind-only-30d` | 已有 MOM6 对照的 0.5° 仅风 30 天问题 | 外部缓存待获取/固定；共享物理与实际预处理另行核对 |
| `global-050deg-restoring-30d` | 上一问题加入共同 30 天温盐恢复 | 同上；恢复属于共同 case 条件 |
| `synthetic-production-smoke-80s` | 安装后有界生产组装、输出、重启工程见证 | 完全生成，无外部下载；没有真实海洋技巧资格 |

`data[].path` 相对 `--root`，也可以是绝对路径。`version` 保存来源版本；`sha256: null` 必须同时声明 `status: pending`，不是已经核验的输入。缺失数据可以展开配置，但不能启动运行。实际运行逐文件固定 SHA256，校验加载角色、路径及运行前后内容；声明了预期校验值的文件必须一致。NetCDF 与 `.nc.npz` 提取缓存不可凭名称认为相同，分别记录实际字节校验值。

合成 case 的经向分辨率为 45°，纬向坐标为 −30° 至 30° 的 8 个点，纬向间距约 8.5714°。它不是角度各向同性的 45° 真实地形模式。安装包服务只构造输入和实际网格；调用同一正式 FD factory、时间积分和输出流程。

MOM6 官方 `tc1` 是另一个小物理问题，定义在 `baselines/mom6/cases/`，不能套用全球 case 身份。来源和配置规范见 [实验说明](../docs/experiments_zh.md)。
