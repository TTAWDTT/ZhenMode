## 只读实现与验证

温盐平流算子可选返回其真正使用的顶面通量。多子步时将通量和
tendency 一起返回、求均值；不在 scan 内修改 Python 记录器，也不拿
起点快照代替实际平均。RK 两次实际求值各计 dt/2。
新增平流、对流、GM、Redi 的实际过程表，顶面恒等式及非线性阶段
重构残差。原外部源表和原 `budget_residual` 未改，内部输运未成为外源。
`A*eta*C_surface` 的线性化库存端点变化单列，不用于守恒 PASS。

新增 16 项回归覆盖全湿/陆地/干底、正负顶面输运、1/3 平流子步、
scan/loop、真实对流子步和非零 GM/Redi、完整 N 阶段及独立 NumPy
海面库存。记录现有闭合实现不代表这些参数化已物理正确。
最初缺少过程 API 时测试无法收集；实现后另有一项完整更新检查失败：
dt=1 s 的端点微小差分受原温盐库存舍入影响，不能只以增量估计误差。
该检查现显式加入 dtype epsilon 乘独立温盐库存的舍入尺度；顶面通量
恒等式的预注册 5e-12 相对绝对输运尺度门槛没有放宽。

冻结内核对照使用 `--ref fb322c6`，在非均匀温盐、非零速度及湿掩膜
样本上，float64/float32 × 有/无冰四组全部六字段最大绝对差为 0。
当前全量测试为 **314 passed，23 warnings**；ruff 和 diff-check 通过，
求解器 MMS ALL PASS，经向制造解收敛比 4.30。旧警告来自已有评分
固定场相关系数与 NumPy shape 设置，不在本轮改动范围。

## 必须继续的工作

下一项物理研究需要统一温盐单元体积、正压自由面输运、RK/子步时层，
先检验常量保持和局部连续方程，再修改积分公式。MOM6 的时间平均正压
输运与 MITgcm 的 h*C 连续性要求见本轮协议；不能直接移植几行公式而
忽略当前节点、湿掩膜、海底和压力梯度定义。

另发现对流子循环同时把 kappa 和 dt 除以 n，疑似使实际扩散率依赖
子步数。该物理问题必须单独预注册、用固定掩膜线性扩散解析/矩阵基准
复现后修复；本轮只读归因不混入改变解的改动。一日样本 conv_nsub=1，
此嫌疑不能解释这里的顶面预算缺口。

独立气候与预报、GPU/分布式及全模式伴随仍未验收。完整目标保持不变。
