# 保守移动顶部带：隔离数学与状态合同

基线 `82e1ca4a2158d4c0ed20f91c04e80cdf43f8a36b`。只有此目录和独立
测试新增；不导入 solver、不接 driver/gate、不读取私有原场、不作时间积分资格。
两柱水平面积各 1 m²，底 z=-20 m，顶部带底 z=-10 m。给定 eta>-10，
目标界面为 `[eta, eta-(eta+10)/4, -10, -20]`；固定 shape 三个严格正厚控制体。
这不是原生产固定节点状态，也不是已证实的真实 1°修复。

## 数学合同

权威状态为物理界面 z 与库存 N=h*(T,S,u,v)，后两字段乘 rho0=1025 kg/m³
才是动量。h=-diff(z)，不可夹厚度或修改给定 eta。每层均值 c=N/h，
重构 `q(z)=c+m*(z-z_center)`；中心 secant minmod、边界单侧 secant。
此 P1 对全局仿射物理剖面精确，对一般曲率/间断不精确，边界外推也不具
普遍 tracer 最大值原理。因此 **qualification_passed=false**，不接生产。

共享面输入是互不交叠的 `(z_lo,z_hi,Q)`，Q 是该物理高度带的总 m³/s，
带内体积通量密度定义为常量 Q/(z_hi-z_lo)。要求整个带属于两柱共同湿面。
用两侧所有界面联合分段，在每个交叠段 s 上，先由 Q 符号选 donor 柱，
再解析积分同一 P1 得 donor 平均；同时更新双方
`Delta h = +/-dt*Q_s`、`Delta N = +/-dt*Q_s*q_donor_average`。
不把相反分层通量聚合为柱总量；单侧层界变化允许，但跨干面输运拒绝。
每 donor 层累计出流不超过原体积的一半；非有限源、非法形状、过量出流、
顶部带耗尽及 eta 与全柱共享体积收支不一致均拒绝并返回调用前深拷贝。
固定床仅在 1e-12 m 舍入一致性检验后写回其精确值，未调整 eta 或厚度正性。

中间体积决定 Lagrangian 界面；以物理交叠积分同一 P1 remap 到目标顶部带。
分字段源是明确的 extensive 库存率，无水源。源改变 tracer 的物理合法性
由调用者负责；本组件只要求有限性，没有偷设温盐或速度裁剪。

压力也积分同一 P1：线性 EOS 异常
`rho'=rho0[-alpha(T-20)+beta(S-35)]`，共同物理深度上
`p=rho0*g*eta + g*integral_depth^eta rho'(z) dz`。
因此同一仿射物理密度、同 eta、不同网格的静止剖面无伪水平梯度。
此处没有压力推进动量，没有压力功/完整机械能守恒资格；曲率压力误差负例
明确保留。不能拿零伪力推出一般压力精度，或拿全局库存闭合推出物理正确。

原 FD 点值的输入桥明确规定为节点间分段线性插值再解析积分；不外推。
9 个 FD 点到 3 个均值的矩阵 rank=3，至少 6 维信息丢失，**一般不可逆**。
不实现伪逆回填生产点值。最小替代设计是保持均值为独立权威状态，再单独
协调需要的高阶矩/原动量质量合同；这属于后续共享语义审查，不在本 PR 实施。

## 混合与能量账

物理 P1 异常 PE 是 `g*sum[h*z_center*rho_mean + h^3*rho_slope/12]`。
均值 KE 是 `rho0/2*sum[h*|u_mean|²]`，重构 KE 额外含
`rho0/24*sum[h^3*|u_slope|²]`。第二温盐矩同样包含斜率项。
记录 transport/source 阶段 KE 变化、remap 均值 KE/PE/温盐第二矩变化。
这些是有符号离散变化，**不是预设非负耗散**；均值 KE 可因网格表示变化而
变化，仿射无输运重网格的重构 KE 保持不变对照专门测试。
完整压力功、源功、隐式混合功与动力推进未实现，不宣称总机械能闭合。

24 个给定输运步中左柱 eta 从 0 到 -3.6 再回 0，确实穿过原 -2.5 m。
循环温盐动量库存全局误差见 evidence.json；局部循环误差逐字段标单位，
不跨单位排名，不要求有损更新字节可逆。remap 均值 KE 总变化约 -0.11254 J、
PE +0.07631 J；这与 PR5 P0 重复不同：P1 仿射 remap 精确，压力和面通量同源。
