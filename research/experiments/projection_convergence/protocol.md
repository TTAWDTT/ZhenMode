## 调研与假设

- [JAX CG](https://docs.jax.dev/en/latest/_autosummary/jax.scipy.sparse.linalg.cg.html)：
  maxiter 是上限而非收敛证明；M 近似逆矩阵，隐式导数要求正向和
  反向求解都收敛，返回 info 当前不提供收敛状态。
- [PETSc CG](https://petsc.org/release/manualpages/KSP/KSPCG/)：相容子空间
  上的对称半正定算子可使用 CG，预条件也要保持对称正性。
- [PETSc Jacobi](https://petsc.org/release/manualpages/PC/PCJACOBI/)：对角
  缩放是低成本候选，零对角位置用单位值，不是向物理算子添加质量项。

H-CONFIG：建模时解析并保存 cap、有效容差、预条件，比 trace 时读取
可变环境更可靠。H-PC：原生 -A*B*G3 的精确对角 Jacobi 可改善地形/
纬度造成的尺度差，但不能预设能消除所有低频/空模问题。

## 预注册门槛与试验

1. 显式工厂参数优先于旧 OCEAN_PAV_NITER；旧环境只在构建时解析一次。
   默认暂保留 none/150；参数无效必须报错，有效参数和来源写入驱动及
   smoke JSON。修改环境不得改变已构建求解器，即使尚未首次 trace。
2. 全湿、陆地/干底台阶、独立孤立湿点：用逐单位基向量生成真实矩阵
   验证对角，float64 相对误差 <= 5e-13。对角非负；干/孤立行安全。
   不修改 B/G3、温盐、边界源或均值，不清零真实顶面。
3. 局部 none/jacobi 都满足已有约束/能量门槛；Jacobi 的 JVP、VJP 与
   独立有限差分/体积负伴随一致，零右端有限。刻意 cap=1 的不收敛
   必须被真实输运诊断检出，不能把“求解返回”当 PASS。
4. 冻结 cce8f87 演化真实 ETOPO/合成初值强迫，2°、180x65x14、±65°、
   80 次地形平滑、最小深度 500m、dt600/dt_bt50、kappa_bi2e14；基线和
   动态冰，float64/32。在第 1、72、144 步采样同一实际 stage-2 预测
   速度。对每个固定右端比较 none/jacobi × cap150/300/600/1200。
   保存输入/源码哈希、原生面积 L2 残差和动能、编译后 CPU 耗时。
5. 候选的每个非零右端残差 <= 1e-9(float64)/5e-5(float32)，有限且
   湿动能不增加至 1e-12/5e-6 相对容差。以上是本阶段应用门槛，
   不是通用行业标准。全部失败也如实保存，不降低门槛。
6. 通过候选再执行完整基线/动态冰一日积分，实际每步最大残差与累计
   面积 L2 分开保存，重新分析热盐水账本。只改求解配置未必消除
   stage-1/自由面时层与体积缺口，不能替代真正守恒修复。
7. 全量 pytest、ruff、MMS；选择默认配置必须有上述实测，不靠小网格
   或 CPU 时间宣称生产/GPU、百年、气候或整模式伴随已获证。
