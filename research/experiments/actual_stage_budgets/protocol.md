# 实际积分阶段预算：预注册协议

日期：2026-09-28；起点 `d9ffce9`。这是完整工业对齐路线 P0 的下一项，
不是将百年、真实气候技巧、全球几何或加速验收缩减为诊断工具。

## 新一轮调研

- [MOM6 原生示踪剂预算](https://mom6-analysiscookbook.readthedocs.io/en/latest/notebooks/Closing_tracer_budgets.html)：广延含量、实际过程 tendency、局部与整体闭合；全局相消不能证明局部正确。
- [MOM6 diagnostics](https://mom6.readthedocs.io/en/main/api/generated/pages/Diagnostics.html)：原生和重映射输出不能混淆，模式过程阶段需要一致的诊断。
- [MITgcm diagnostics](https://mitgcm.readthedocs.io/en/latest/outp_pkgs/outp_pkgs.html)：变厚度诊断需要平均厚度乘量，而不是把平均浓度乘平均厚度。
- [ECCOv4 原生预算说明](https://ecco-group.org/docs/evaluating_budgets_in_eccov4r3_updated_20220118.pdf)：快照用于端点含量，平均通量用于区间输入；预算公式依赖自由面/垂向配置，不能移植成任意配置的证明。

当前 `terms_fn` 是快照处瞬时 tendency，不能乘长时间区间充当累计输入。
当前 `compute_budget_diagnostics.total_volume_m3` 只计固定节点参考水体；
它不含 eta，因而“恒定”不是实际自由面体积已获证。

## 实现原则

1. 在原 `_step_impl` 的实际 L/N/L、自由面、极盖/掩膜、海冰调用中记录，
   不能复制一个诊断用的近似时间积分器。关闭诊断时保留原公共返回 arity。
2. 从实际 RK 两次求值各按 dt/2 累计规定热通量、bulk/coastal bulk、
   温盐恢复与静态盐源；冰模式不重复计已关掉的动力学热源。
3. 线性阶段单列扩散与显式海绵源；海冰按实际气海热输入、相变盐源计账。
   极盖、掩膜、扩散、平流等不允许自动声明为“外部源”来消去漏损。
4. 测得端点变化、阶段分解之和、累计已知源、未解释残差分别返回。
   分解闭合是实现完整性检查，已知源闭合才是守恒检查；两者不能混称。
5. 用 float64 汇总实际保存状态的变化，同时保留 float32 更新的量化残差。
   不补偿温盐均值、不截断坏指标、不更改失败门槛。

## 度量与范围

固定节点水热 `rho0*cp*sum(A*dz_node*wet*T)` 与冰潜热
`rho_ice*Lf*sum(A*wet_surface*ice)` 的差为本轮水冰焓代理。
水盐是 `rho0*sum(A*dz_node*wet*S/1000)`；海面位移体积变化
`sum(A*wet_surface*delta_eta)` 单独计账。

这些度量是对当前离散状态的审计，不冒充含真实淡水、盐冰库、可变层厚
和部分单元的完整物理海洋预算。后续 P1 必须统一体积/自由面/输运；
本轮不能把 eta 温盐含量缺失简单用全局扣均值修成 PASS。

## 实现验收与反证

- 普通与审计步六个状态字段在 float64/float32、split/monolithic、
  scan/loop、启用/禁用冰等样本上相符（精确或不超过 32 个相应 eps
  的舍入容差）；审计不能改写积分解。
- 阶段之和恢复测得端点变化；另与独立 NumPy 端点库存计算比较。
  浮点容差以实际局部变化绝对量为尺度，不以巨大初始全球库存掩盖残差。
- 恒定规定热输入、线性 SST bulk 的 RK2 解析累计、温盐恢复与海绵、
  现有冰生长/完全融化，各有独立公式或算例检查源输入。
- 人为向本应守恒的扩散注入小热源，必须在未解释残差中检出，而不是
  被阶段分解或“闭合补偿”吞掉；float32 低于更新量化的热输入不能报零残差。
- 运行时强迫的不同 Q/气温必须产生不同累计输入，不能读旧闭包常量。
- 现有测试、lint、MMS 与既有求解器回归通过。
- 可复现真实地形短跑同时给出分解残差和未解释残差；即使数值稳定而
  未解释残差非零，也完整记录并研究，而不是标记全模式预算已达标。
