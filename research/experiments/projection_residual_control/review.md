# 残差控制：六条完整短轨迹通过，物理体积预算仍未闭合

更新：2026-09-29。协议先提交于 `3804066`，冻结比较内核 `8e51726`，
修正数值内核 `2042ce1`。
本文件记录阶段证据，不是百年、气候或完整体积守恒认证。

## 固定输入与因果分解

`analyze_refinement.py` 按原 JSON 的 SHA256 验证 12 个粗采样预测速度
和 2 个最坏 float32 快照，共 14 份输入；完成 86 次候选求解。
原始结果/源码与输入哈希位于
`results/industrial_alignment/projection_refinement.json`。首次实验在
数值源码未改动时完成；源码可与冻结 `8e51726` 逐项核对。
诊断图是固定快照的独立图，不冒充完整轨迹逐位重演。

公开 CG 重建与原公共投影的速度最大差均为零；独立镜像的压力与
公开 CG 最大差也均为零。在两个最坏 float32 快照上：

| 快照 | 迭代数 | 递推停止相对残差 | 重算 b-Apsi 相对残差 |
| --- | ---: | ---: | ---: |
| 基线第13步 | 244 | 3.647e-6 | 4.957e-5 |
| 冰第9步 | 244 | 3.572e-6 | 4.993e-5 |

有效 rtol=3.815e-6；递推满足停止条件但真实矩阵残差约大 14 倍。
因此此处确有有限精度残差分离，不能仅把 CG 返回当收敛。矩阵
欧氏范数和实际原生输运面积范数不同，仍须检查后者。

| float32 候选 | 通过数 | 最坏原生面积 L2 比 |
| --- | ---: | ---: |
| 单次 CG | 6/8 | 5.437e-5 |
| 势函数真残差修正1次 | 8/8 | 5.223e-6 |
| 势函数真残差修正2次 | 8/8 | 4.335e-6 |
| 速度再投影1次 | 8/8 | 4.176e-6 |
| 速度再投影2次 | 8/8 | 4.176e-6 |
| 一致float64解再量化 | 8/8 | 6.156e-7 |

float64 每个候选均 6/6 通过，最坏约 1.067e-12。所有表中 PASS
还要求有限、状态 dtype 不变、湿动能满足原门槛。没有放宽既有
1e-9/5e-5 门槛。相同输入下高精度参照约 0.4--0.5 秒，32 位速度
修正约 0.16--0.17 秒；有短时并发合成探索，计时仅用于诊断成本，
不是隔离硬件的性能验收，也不是全模式或 GPU 的速度结论。

关键负对照：二次求解不保留原 RHS 的绝对停止下限时，两个最坏
快照的原生残差放大至 0.281/0.113；动能较单次投影后的值增加，
但仍低于原始预测速度的动能，因此原注册的动能上界并未失败。
不能把残差失败误报为所有门槛都失败。半正定系统上
追逐噪声右端的极小相对误差不是可靠修法，这两项失败完整保留。

## 核心选择与直接反证

选择保留状态/压力精度的速度再投影，原生 Fz 超过预定内部目标时
至多两次；修正 CG 用原始右端定义绝对停止下限。原生规范使用
实际 reverse-cumsum Fz，而非仅势函数 b-Apsi 或 CG 内部递推。
不添加正则、改均值、清顶面、改源表或温盐，也不将整模式切成64位。
内部目标是触发值，不是无条件已达到的承诺；有界求解仍可能失败。

独立合成回归不依赖本地 NPZ：128x96、4节点、±65°、干陆地和底
台阶，平滑正弦压力的纯梯度预测速度。在旧内核 Jacobi/600 下实际
残差 1.129e-4，已有 5e-5 断言失败。96x64 探针为 4.802e-5；保留
这次未超过验收线的探索记录，不假称最小尺寸也复现相同失败。
修正后第一轮 37 项投影直接回归通过；扩展后 45 项通过，包括主动
float32 修正分支的局部 JVP/有限差分和 VJP 双线性一致性、关闭修正
保留原失败、配置有效性及 dtype/停止尺度来源。这不证明整个模型
伴随或所有反向右端均收敛。旧 none/150 的全局生产资格不能因修正
存在而自动成立。

## 物理缺口与准确范围

2°的float64固定节点热代理残差仍为-2.028e21/-2.042e21J，顶面
输运几乎完全解释此代理变化，但加线性化海面库存仍留下
+2.052e21/+2.083e21J，不能称作真正守恒。float32同样保留库存/
记账精度问题，1°残差约-2.108e21/-2.123e21J，未因压力求解通过
而被认证；动态冰的水盐库存也仍需物理闭合。

实际2°网格180x66x14、中心±65°、整格至±66°；1°为360x130x14、
整格至±65°，不能当作完全同域的空间收敛实验。原JSON和NPZ始终
记录正确形状；已公开更正此前ny=65的文字，保留旧注册偏差说明。

Legacy none/150仍不升级为通用安全默认；当前通过的是明确配置、
网格和短轨迹，不是任何参数下的生产承诺。下一优先项是已量化的
[体积与时间平均输运不一致](../volume_transport_consistency/review.md)，
不是继续围绕CG调分数。真实强迫百年、独立气候/预报、完整物理/
几何、GPU/分布式、全模式伴随及工程交付的完整目标继续保持。
