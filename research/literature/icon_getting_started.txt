Tutorials, documentation, and discussion
The ICON tutorial
summarizes the mathematical and physical foundations as well as the most important aspects for using the ICON model.
Further documentation will be added on an ongoing basis and can be found on the official docs page:
https://docs.icon-model.org/
If you have any questions about installing or using ICON, we encourage users to help one another and to use the following platform:
https://exchange.icon-model.org/
