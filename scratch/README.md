
# Scratch

This directory is ignored on purpose. It is for local artifacts that should not
be treated as project source: legacy probe outputs, temporary downloads,
presentations, and superseded experiment snapshots.

Layout:

- `legacy_root/` — one-off root-level probe scripts and logs
- `legacy_data/` — old locally generated init files
- `legacy_refs/` — downloaded reference pages
- `legacy_runs_gm5d/` — old scratch run output
- `legacy_ana_tmp/` — legacy analysis scratch
- `papers_presentations/` — local papers/slides

Do not put anything here that you want tracked or reused by the mainline code.
